# Young’s Physics 주간 기본 복습 테스트 성적 분석 시스템 개발·인수인계 지침

> **목적**  
> 다른 새 채팅에서 이 파일과 시험지·해설지·학생 결과 파일만 전달하면, 기존 Young’s Physics 성적 분석 시스템의 장점과 오류 방지 원칙을 이어받아 **물리1·물리1심화·물리2 주간 복습 테스트용 성적 분석 사이트**를 바로 제작하거나 확장할 수 있도록 하는 기준 문서이다.

> **중요한 분리 원칙**  
> 기존 TPL 모의고사 시스템의 실제 학생 데이터, 정답표, Google Sheet, Apps Script 배포 주소와 토큰을 그대로 재사용하지 않는다.  
> 디자인, 중앙 저장, 학생 링크, 오답 학습, Word/PDF 출력, 링크 무결성 등 검증된 기능과 개발 원칙만 참고한다.

# 0. 새 채팅에서 가장 먼저 전달할 지시문

아래 문장을 새 채팅의 첫 메시지로 붙여넣고, 이 마크다운 파일과 새 시험 자료를 함께 첨부한다.

> GitHub Pages와 Google Sheets + Apps Script를 이용하여 **Young’s Physics 주간 기본 복습 테스트 성적 분석 시스템**을 만들어줘.  
> 첨부한 `YoungsPhysics_주간기본복습테스트_성적분석시스템_개발인수인계.md`를 최우선 제작 기준으로 사용해줘.
>
> 시험 과정과 회차는 다음과 같아.
>
> - 물리1: 1~8회, 10~16회
> - 물리1심화: 1~6회
> - 물리2: 1~9회, 11~15회
>
> 물리1 9회와 물리2 10회는 현재 운영 목록에 포함하지 마. 나중에 자료가 제공되면 별도로 추가해줘.
>
> 시험마다 문항 수, 객관식·주관식 구성, 문항별 배점, 만점이 서로 다르다.  
> 학생의 실제 답안 문자열을 자동 채점하지 않고, 교사가 문항별로 다음 값을 입력해 점수를 확정하는 구조로 만들어줘.
>
> - `0`: 틀림, 0점
> - `1`: 맞음, 해당 문항의 전체 배점 획득
> - 그 밖의 유효한 숫자: 해당 숫자만큼 부분점수 획득
> - 빈칸: 미입력 또는 미채점
>
> `1`은 “1점”이 아니라 “정답·만점”을 뜻한다. 배점이 2점 이상인 문항에서 정확히 1점의 부분점수를 입력해야 할 때는 `P1` 또는 부분점수 모드의 `1`로 입력할 수 있게 해줘.
>
> 내가 시험지와 해설지를 올리면 다음을 먼저 검수해줘.
>
> - 정답과 풀이가 실제로 맞는지
> - 문제 조건이 충분한지
> - 보기와 공식 정답이 일치하는지
> - 객관식 정답이 하나인지
> - 주관식 모범답안과 부분점수 기준이 타당한지
> - 그림·그래프·수식·단위·문항 번호·배점이 누락되거나 잘못되지 않았는지
>
> 검수에서 문제가 없으면 그대로 적용하고, 오류가 있으면 수정 근거와 함께 교정한 뒤 사이트에는 검증된 정답·해설을 적용해줘. 애매하거나 복수 정답 가능성이 있는 문항은 자동 공개하지 말고 `확인 필요`로 표시해줘.
>
> 학생별 결과 링크에는 다음이 포함되어야 해.
>
> - 해당 회차 점수와 백분율
> - 같은 과정·같은 회차 학생들의 평균 점수
> - 문항별 획득 점수와 전체 평균
> - 단원별 강점·보완 영역
> - 틀린 문항과 부분점수 문항의 원문 문제
> - 검수된 해설, 필요한 공식, 자주 하는 실수
> - 같은 풀이 방법을 사용하는 새 동형 문제
> - 해당 회차 문제풀이에 필요한 핵심 개념·공식 요약
>
> 석차와 백분위는 기본 화면에 표시하지 않아도 돼. 현재 회차 전체 평균과 문항별 평균 정도를 중심으로 분석해줘.
>
> 동형 문제는 처음부터 정답과 풀이가 보이면 안 돼. 학생이 답을 제출한 뒤 정답과 해설이 공개되게 해줘.
>
> 학생 정보와 점수는 Google Sheets에 자동 저장하고 다른 컴퓨터에서도 동기화되어야 해. 학생마다 무작위 결과 링크를 만들고 버튼 한 번으로 저장·성적표 생성·링크 복사가 완료되게 해줘.
>
> 학생 링크가 다른 학생 성적표로 연결되는 일이 없도록 서버 토큰과 학생 지문을 함께 검증해줘.
>
> Word 저장은 HTML에 `.doc` 확장자만 붙이지 말고 실제 `.docx`로 생성해줘. 로고·그래프·문제 이미지·해설 그림을 Word 문서 내부에 삽입하여 다른 컴퓨터에서도 깨지지 않게 해줘.
>
> 작업 완료 후 전체 프로젝트 ZIP, 수정 파일 패치 ZIP, Apps Script `Code.gs`, 설치 안내서, 데이터 입력 예시, 화면 미리보기, Word/PDF 예시, 문제·해설 검수 보고서와 테스트 결과를 함께 제공해줘.

# 1. 시스템 목적

매주 진행되는 기본 복습 테스트를 과정·회차별로 관리하고, 교사가 학생의 문항별 성취 결과를 입력하면 다음을 자동으로 생성한다.

1. 학생별 성적표
2. 같은 과정·같은 회차 응시자 평균과 비교 분석
3. 문항별·단원별 성취 분석
4. 틀린 문항과 부분점수 문항의 보완 학습
5. 해당 회차 핵심 개념·공식 요약
6. 같은 풀이 방식의 동형 문제
7. 학생별 무작위 결과 링크
8. Word·PDF·인쇄용 리포트

이 시스템은 학생의 실제 객관식 선택 번호나 주관식 답안을 기본 입력값으로 요구하지 않는다.  
교사가 학생의 채점 결과를 보고 **문항별 성취값**을 입력한다.

# 3. 시험마다 달라질 수 있는 항목

각 시험은 다음 정보가 독립적으로 설정되어야 한다.

- 문항 수
- 총점
- 문항별 배점
- 문항 유형
- 대단원
- 세부 개념
- 난이도
- 원문 문제 이미지
- 공식 정답 또는 모범답안
- 해설
- 필요한 공식
- 채점 기준
- 부분점수 기준
- 동형 문제
- 시험지 PDF
- 해설지 PDF
- 시험 날짜
- 제한 시간

문항 수와 만점을 코드에 고정하면 안 된다.

```text
총점 = 모든 문항의 최대 배점 합
학생 점수 = 모든 문항의 실제 획득 점수 합
성취율 = 학생 점수 ÷ 시험 총점 × 100
```

# 4. 학생 문항 결과 입력 규칙

## 4.1 기본 입력 의미

각 문항 입력값은 다음과 같이 해석한다.

| 입력값 | 의미 | 획득 점수 |
|---|---|---:|
| `0` | 틀림 | 0점 |
| `1` | 맞음 | 해당 문항 최대 배점 |
| 그 밖의 숫자 | 부분점수 | 입력한 점수 |
| 빈칸 | 미입력·미채점 | 총점 확정 전 경고 |

예를 들어 문항 최대 배점이 4점이면:

```text
0   → 0점
1   → 4점
2.5 → 2.5점
4   → 4점
```

문항 최대 배점이 7점이면:

```text
0   → 0점
1   → 7점
3   → 3점
5.5 → 5.5점
```

## 4.2 정확히 1점의 부분점수 처리

`1`은 정답·만점을 뜻하므로, 최대 배점이 2점 이상인 문항에서 학생이 정확히 1점만 받은 경우를 별도로 표현해야 한다.

다음 중 하나를 반드시 지원한다.

```text
P1
p1
1점
```

또는 문항 입력칸에서 `부분점수 모드`를 선택한 뒤 숫자 `1`을 입력한다.

권장 파싱:

```text
1   → 만점
P1  → 부분점수 1점
```

## 4.3 유효성 검사

- 부분점수는 0보다 크고 해당 문항 최대 배점 이하여야 한다.
- 최대 배점을 초과하면 저장 차단
- 음수 차단
- 숫자가 아닌 잘못된 값 차단
- 소수점 허용
- 입력값이 최대 배점과 같으면 `정답·만점`으로 정규화
- 모든 문항이 빈칸인 학생은 저장 차단
- 일부 빈칸이 있으면 미채점 경고 후 교사 확인

## 4.4 점수 상태

각 문항은 다음 상태 중 하나로 저장한다.

```text
full       만점
partial    부분점수
wrong      0점
ungraded   미입력·미채점
```

객관식과 주관식 모두 같은 입력 규칙을 사용하지만, 학생 리포트의 해설과 동형 문제는 문항 유형에 맞게 제공한다.

# 5. 입력 화면 요구사항

## 5.1 학생 정보

- 학생 이름: 필수
- 학교: 선택
- 학년: 선택
- 반·번호: 선택
- 과정: 필수
- 회차: 필수
- 교사 메모: 선택

학교를 비우면 자동으로 다음 값으로 저장한다.

```text
미입력
```

## 5.2 문항 입력 그리드

시험 설정에 등록된 문항 수만큼 자동 생성한다.

각 문항 카드 또는 행에 표시:

- 문항 번호
- 문항 유형
- 최대 배점
- 입력칸
- 해석된 상태
- 실제 획득 점수
- 문항 단원

예시:

```text
3번 · 객관식 · 4점
입력: 1
결과: 정답 · 4/4점
```

```text
8번 · 주관식 · 5점
입력: 2.5
결과: 부분점수 · 2.5/5점
```

## 5.3 키보드 입력

- 값을 입력하면 자동으로 다음 문항으로 이동
- Backspace로 이전 문항 이동
- 위·아래 화살표로 이동 가능
- `0`, `1`, 부분점수 숫자, `P1` 입력 지원
- 개별 문항 비우기 버튼
- 전체 초기화 버튼

## 5.4 엑셀·Google Sheets 붙여넣기

탭으로 구분된 값을 그대로 붙여넣을 수 있어야 한다.

```text
1	1	0	2.5	1		P1	0
```

빈 탭은 해당 문항의 미입력 위치로 유지한다.  
빈 셀을 제거하고 뒤 문항 값을 앞으로 당기면 안 된다.

지원 구분자:

- 탭
- 쉼표
- 줄바꿈
- 연속 쉼표

시험 문항 수보다 입력값이 많거나 적으면 경고한다.

## 5.5 CSV 일괄 입력

시험별 문항 수가 다르므로 동적 헤더를 생성한다.

예시:

```csv
과정,회차,학교,이름,학년,반번호,Q1,Q2,Q3,Q4,Q5,Q6
물리1,1회,,홍길동,2,,1,1,0,2.5,P1,1
```

가져오기 전 다음을 미리 보여준다.

- 학생 이름
- 계산된 점수
- 만점
- 성취율
- 오류 문항
- 신규 저장 또는 기존 수정 여부

# 6. 상단 고정 점수·저장 패널

학생 입력 화면 상단에 스크롤 중에도 보이는 패널을 둔다.

실시간 표시:

```text
학생 이름
현재 점수 / 시험 만점
성취율
만점 문항 수
부분점수 문항 수
0점 문항 수
미입력 문항 수
입력 완료 문항 수 / 전체 문항 수
```

큰 기본 버튼:

```text
저장 및 성적표 생성
Google Sheets 저장 후 결과 링크 자동 복사
```

버튼 한 번으로 다음 작업을 수행한다.

1. 입력값 검증
2. 점수 계산
3. Google Sheets 저장
4. 같은 과정·같은 회차 전체 통계 재계산
5. 학생 성적표 토큰 생성
6. 학생 링크 생성
7. 클립보드 자동 복사
8. 링크 생성 완료 창 표시

# 7. 신규 학생·수정·동명이인 처리

## 7.1 기록 식별 기준

기본 학생 식별 조합:

```text
examId + 학교 + 학생 이름
```

필요하면 학년·반번호를 추가한다.

## 7.2 기존 학생 수정

학생 기록 목록에서 `수정` 버튼을 눌러 편집 모드에 들어간 경우:

- 기존 행 갱신
- 기존 서버 토큰 유지
- 기존 학생 링크 유지
- 이름 자동 번호 추가 금지

## 7.3 동일 시험·동일 학교·동명이인 신규 입력

편집 모드가 아닌 상태에서 같은 시험·학교·이름을 새로 입력하면 기존 학생을 덮어쓰지 않는다.

```text
첫 번째: 홍길동
두 번째: 홍길동2
세 번째: 홍길동3
```

다른 학교나 다른 회차에는 번호를 공유하지 않는다.

```text
물리1 1회 · A고 · 홍길동
물리1 1회 · B고 · 홍길동
물리1 2회 · A고 · 홍길동
```

이 세 기록은 각각 숫자 없이 저장 가능하다.

# 8. 시험지·해설지 검수 절차

시험 자료를 받으면 사이트에 바로 넣지 말고 먼저 검수한다.

## 8.1 검수 대상

- 공식 정답
- 해설 계산
- 풀이 논리
- 문제 조건
- 보기 구성
- 복수 정답 가능성
- 객관식 정답 개수
- 주관식 모범답안
- 부분점수 기준
- 문항 번호
- 문항별 배점
- 총점
- 단위
- 기호
- 그래프 축
- 그림 누락
- 수식 잘림
- 문제와 해설의 불일치

## 8.2 검수 상태

각 문항에 다음 상태를 부여한다.

```text
verified       원문 정답·해설이 타당함
corrected      오류를 교정하여 적용함
ambiguous      조건 부족 또는 복수 해석 가능
needs-review   교사 확인이 필요함
```

## 8.3 적용 원칙

- `verified`: 그대로 적용
- `corrected`: 교정된 정답·해설 적용, 교정 메모 표시
- `ambiguous`: 자동 학습 자료 공개 보류
- `needs-review`: 교사 확인 후 활성화

공식 해설이라고 해서 무조건 정답으로 간주하지 않는다.

## 8.4 검수 보고서

회차를 추가할 때 별도의 검수 보고서를 만든다.

| 문항 | 상태 | 발견 내용 | 적용 내용 |
|---|---|---|---|
| 3번 | verified | 이상 없음 | 원문 적용 |
| 7번 | corrected | 정답표와 풀이 불일치 | 정답 ④로 교정 |
| 11번 | needs-review | 보기 값 누락 | 교사 확인 전 비활성 |

# 10. 학생 성적 리포트

## 10.1 상단 요약

- 로고
- 과정명
- 회차
- 학생 이름
- 학교
- 시험일

- 평균 성취율
- 응시 인원

석차와 백분위는 기본 화면에서 표시하지 않는다.

## 10.2 요약 카드

- 만점 문항 수
- 부분점수 문항 수
- 0점 문항 수
- 미입력 문항 수
- 학생 점수
- 전체 평균

## 10.3 전체 비교 그래프

표시 권장:

- 학생 점수
- 동일 회차 전체 평균
- 중앙값
- 최고점
- 점수 분포

석차 숫자를 표시하지 않더라도 분포상 학생 위치를 시각적으로 보여줄 수 있다.

## 10.4 문항별 분석표

| 문항 | 유형 | 단원 | 최대 배점 | 학생 점수 | 상태 | 전체 평균 |
|---|---|---|---:|---:|---|---:|
| 1 | 객관식 | 운동 | 3 | 3 | 만점 | 2.4 |
| 2 | 주관식 | 에너지 | 5 | 2.5 | 부분점수 | 3.1 |
| 3 | 객관식 | 전기 | 2 | 0 | 틀림 | 1.2 |

## 10.5 단원별 분석

```text
단원 성취율
= 해당 단원 학생 획득 점수
  ÷ 해당 단원 최대 점수
  × 100
```

표시:

- 학생 단원 성취율
- 동일 회차 전체 평균 성취율
- 관련 문항 수
- 강점·보완 필요 상태

## 10.6 자동 코멘트

현재 회차만 근거로 작성한다.

포함할 내용:

- 잘한 단원
- 보완할 단원
- 부분점수를 잃은 풀이 단계
- 우선 복습 문항
- 구체적인 학습 행동

이전 회차 상승·하락 분석은 기본 기능에 넣지 않는다.

# 12. 동형 문제 기능

동형 문제는 원문과 수치·상황을 바꾸되 같은 풀이 원리를 사용한다.

## 12.1 객관식 동형 문제

처음 표시:

- 문제
- 그림
- 선택지

숨김:

- 정답
- 해설

학생이 답을 선택하면:

- 선택한 답의 정오 표시
- 정답 공개
- 같은 풀이 방식 설명
- 전체 해설 공개
- `다시 풀기` 버튼 표시

## 12.2 주관식 동형 문제

- 숫자 또는 짧은 답 입력
- `답 제출` 버튼
- 제출 전 정답 숨김
- 제출 후 모범답안과 풀이 공개
- 자동 채점이 불안정한 서술형은 자기 점검 방식 사용
- 단계별 체크리스트 제공

## 12.3 제작 기준

- 원문 문장을 단순 복사하지 않음
- 숫자만 무의미하게 바꾸지 않음
- 같은 개념과 풀이 절차 유지
- 조건의 물리적 타당성 검증
- 답과 해설을 직접 다시 계산
- 난이도는 원문과 비슷하게 유지

# 22. 필수 테스트

## 22.1 입력·점수

- `0` → 0점
- `1` → 문항 만점
- `2.5` → 2.5점
- `P1` → 정확히 1점 부분점수
- 최대 배점 초과 차단
- 음수 차단
- 빈칸 위치 보존
- 서로 다른 문항 수 시험 지원
- 서로 다른 총점 지원

## 22.2 평균

예시:

```text
같은 시험 학생 A: 20/20
같은 시험 학생 B: 10/20
신규 학생 C: 15/20
```

결과:

```text
응시 인원: 3명
평균: 15점
```

다른 회차 학생은 포함하지 않는다.

## 22.3 링크

- 학생별 다른 토큰
- 다른 학생 성적표 오연결 없음
- 동일 학생 수정 시 기존 링크 유지
- 동명이인 신규 저장 시 이름2, 이름3 부여
- 잘못된 지문이면 리포트 표시 차단

## 22.4 동기화

```text
컴퓨터 A에서 저장
→ Google Sheet Reports 행 생성
→ 컴퓨터 B에서 서버 새로고침
→ 동일 학생 표시
```

## 22.5 동형 문제

- 선택 전 정답 숨김
- 선택 후 정답·해설 공개
- 다시 풀기 초기화
- 객관식·주관식 유형별 작동

## 22.6 Word

- 실제 `.docx`
- 외부 이미지 연결 0개
- 로고 정상
- 그래프 정상
- 문제 그림 정상
- 다른 컴퓨터에서 깨짐 없음
- PDF 변환 정상

## 22.7 과정·회차 분리

- 물리1과 물리2 통계 혼합 금지
- 다른 회차 통계 혼합 금지
- 물리1 9회가 임의 생성되지 않음
- 물리2 10회가 임의 생성되지 않음
- 총 35개 운영 회차 구조 확인

# 23. 완료 판정 시나리오

1. 물리1 1회 시험지와 해설지를 업로드한다.
2. 시스템이 문항 수·배점·문항 유형을 확인한다.
3. 정답과 해설을 검수하고 보고서를 만든다.
4. 검증된 문항만 사이트에 등록한다.
5. 교사가 학생 이름과 문항별 `0`, `1`, 부분점수를 입력한다.
6. 상단에 현재 점수와 만점이 즉시 표시된다.
7. 저장 버튼을 한 번 누른다.
8. Google Sheets에 기록이 저장된다.
9. 같은 물리1 1회 학생 평균이 재계산된다.
10. 학생별 링크가 자동 복사된다.
11. 학생이 링크에서 점수와 전체 평균을 확인한다.
12. 단원별 강점·보완 영역을 확인한다.
13. 틀린 문항과 부분점수 문항의 해설을 확인한다.
14. 동형 문제를 직접 풀고 제출 후 해설을 본다.
15. 회차 핵심 개념·공식 요약을 확인한다.
16. Word·PDF·인쇄로 저장한다.
17. Word 안의 로고·그래프·문제 이미지가 깨지지 않는다.
18. 다른 컴퓨터의 교사용 사이트에서도 같은 학생 기록을 확인한다.
19. 다른 학생 링크가 잘못 열리지 않는다.
20. 석차는 기본 리포트에 나타나지 않고 평균 중심으로 분석된다.

# 25. 개발 중 최우선 판단 기준

요구사항이 충돌하면 다음 순서로 판단한다.

1. 시험마다 문항 수·배점·총점이 다름
2. `0`은 틀림·0점
3. `1`은 맞음·문항 만점
4. 그 밖의 숫자는 실제 부분점수
5. 정확히 1점의 부분점수는 `P1` 등 별도 입력 지원
6. 같은 과정·같은 회차 평균만 계산
7. 석차는 기본 표시하지 않음
8. 시험지·해설 검수 후 검증된 내용만 적용
9. 학생별 오답·부분점수 보완 학습 제공
10. 회차 핵심 개념·공식 요약 제공
11. 학생 데이터는 Google Sheets를 원본으로 사용
12. 학생 링크 토큰·지문 무결성 보장
13. 저장·링크 복사를 한 번의 버튼으로 수행
14. Word·PDF에서 그림이 깨지지 않음
15. 공개 GitHub에 학생 개인정보를 넣지 않음

# 26. 새 채팅에 함께 첨부할 자료

- 이 마크다운 파일
- 시험지 PDF
- 해설지 PDF
- 문항별 배점표
- 학생 결과 Excel 또는 CSV
- 사용할 로고 PNG
- 서술형 채점 기준
- 원하는 화면 예시
- 새 Google Sheet 주소 또는 ID

시험지는 추후 순차적으로 제공해도 된다.  
자료가 없는 회차는 과정·회차 목록에만 등록하고 문항 페이지는 `준비 중` 상태로 둔다.
