# Young’s Physics 로고 기반 UI·리포트 리브랜딩 변경 내역

- 프로젝트 버전: **2.1.0**
- 적용 기준: 사용자가 제공한 Young’s Physics 공식 원자 로고
- 변경 범위: GitHub Pages 교사용 화면, 학생·학부모 리포트, 설치 안내, 실제 DOCX 출력, 총괄 문제 이미지 crop 보정
- 서버 영향: **없음** — Apps Script와 Google Sheets 스키마는 2.0.0과 동일

## 1. 적용한 브랜드 체계

공식 로고의 색상과 형태를 기준으로 다음 공통 디자인 토큰을 적용했습니다.

| 요소 | 적용 내용 |
|---|---|
| 주 색상 | 짙은 남색, 로열 블루, 밝은 블루, 흰색 |
| 배경 | 흰색 및 매우 옅은 청색 그라데이션 |
| 카드 | 큰 둥근 모서리, 얇은 청색 테두리, 절제된 그림자 |
| 강조 | 점수·핵심 버튼은 파란 그라데이션, 오답은 빨강, 부분점수는 주황 |
| 과학 모티프 | 원자 궤도, 점·선 네트워크, 물리 공식 장식 |
| 타이포그래피 | 명확한 제목–본문–보조 정보 위계와 넉넉한 여백 |

## 2. 교사용 사이트 변경

- 상단 로고와 메뉴를 갖춘 브랜드 헤더 적용
- 물리 공식을 배경으로 한 과학 학습 관리형 히어로 영역 추가
- 학생 정보와 시험 선택을 독립 카드로 재배치
- 입력 진행률과 현재 점수를 보여 주는 원형 점수 링 추가
- 문항별 입력 카드의 배점·단원·상태를 한눈에 구분하도록 개선
- `저장·성적 분석·링크 복사` 버튼을 고정형 핵심 동작으로 강조
- CSV 일괄 입력, 서버 기록 목록, 설정 모달을 같은 디자인 체계로 통일
- 모바일에서 메뉴·입력 카드·버튼이 화면 밖으로 밀리지 않도록 반응형 규칙 적용

## 3. 학생·학부모 리포트 변경

- 로고와 시험명을 포함한 리포트 표지형 상단 구성
- 큰 총괄 점수와 성취율, 동일 평가 평균을 파란 점수 패널에 배치
- 연결된 주간 복습 기록과 총괄평가를 한 화면에서 비교
- 강점 단원·보완 단원 카드와 단원별 레이더 차트 적용
- 문항별 획득 점수·전체 평균·상태를 표와 막대로 표현
- 틀린 문제와 부분점수 문제를 브랜드 카드 형태로 재구성
- 원문 재도전 제출 전 해설 숨김, 제출 후 해설 공개, 동형 문제 해금 순서를 그대로 유지
- Word, PDF, 인쇄, 링크 복사 버튼을 상단 우측에 크게 배치
- 모바일 리포트의 레이더 차트·표·오답 카드 가로 넘침 제거

## 4. Word DOCX 출력 변경

- HTML 파일의 확장자만 바꾸는 방식이 아닌 실제 OOXML `.docx` 유지
- 공식 로고를 문서 내부 `word/media/`에 삽입
- 화면과 동일한 남색·파란색·흰색 표지와 점수 카드 적용
- 총괄·복습 비교 그래프, 단원별 레이더 차트, 문항 분석 표 포함
- 오답 원문 문제 이미지를 문서 내부에 삽입하여 오프라인에서도 표시
- 긴 이미지의 최대 폭·높이를 제한해 페이지 밖 잘림 방지
- 핵심 개념 노트 앞의 불필요한 강제 페이지 나눔을 제거해 빈 페이지 방지

최종 예시는 A4 **15페이지**, 내부 이미지 **13개**, 외부 이미지 관계 **0개**로 검증했습니다.

## 5. 문제 이미지 표시 보정

리포트와 DOCX에서 총괄평가 서술형 문제 이미지에 큰 빈 답안 공간이 함께 보이지 않도록 crop 데이터를 보정했습니다.

- 물리1 역학 총괄 11~20번의 렌더 페이지 연결을 실제 시험 페이지에 맞게 교정
- 물리1 역학 21~25번 서술형 원문을 문제·그림 중심으로 축소 crop
- 물리1 전자기·파동 21~25번 서술형 원문을 문제·그림 중심으로 축소 crop
- 카탈로그 JSON과 브라우저용 JS 데이터의 값을 동일하게 동기화

정답·해설·채점 결과와 총괄–복습 연결 정책은 변경하지 않았습니다.

## 7. 유지된 기능·보안 원칙

- 총괄 객관식 1~20번 `0/1`, 서술형 21~25번 실제 `0~4점` 입력
- 기존 주간 복습의 `0`, `1=만점`, `P1=정확히 1점`, 일반 부분점수 규칙
- Google Sheets 원본 저장과 다른 컴퓨터 동기화
- 총괄평가별 지정 복습 회차 연결
- 서버 토큰, HMAC 학생 지문, 학생 식별 다이제스트 검증
- 한 버튼 저장·통계 재계산·성적표 생성·링크 복사
- 정답·해설의 단계별 공개와 동형 문제 기능
- 실제 OOXML DOCX 및 PDF·인쇄
- 공개 GitHub 저장소에 학생 개인정보와 쓰기 키를 포함하지 않는 원칙

## 9. 배포 영향

### 기존 통합판 2.0에 디자인만 적용

패치 ZIP을 덮어쓴 뒤 GitHub Pages만 다시 배포합니다. `Code.gs`, Google Sheets, Apps Script 배포 URL과 보안 키는 건드리지 않습니다.

### 신규 설치 또는 총괄평가 통합 기능을 처음 적용

전체 프로젝트 ZIP과 `INSTALL_KO.md`의 전체 설치 절차를 사용합니다. 이 경우에는 Apps Script 설정·재배포와 시험 설정 서버 동기화가 필요합니다.
