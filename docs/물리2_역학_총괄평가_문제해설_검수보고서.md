# 물리2 역학 총괄평가 문제·해설 검수 보고서

## 기본 구성

- 시험: 물리 II 진단고사(역학)
- 객관식: 1~20번, 각 4점
- 서술형: 21~25번, 각 4점
- 총점: 100점
- 입력 정책: 1~20번 학생 선택번호 1~5, 21~25번 실제 획득점수 0~4

## 객관식 검증 정답

`3, 5, 4, 4, 3, 1, 4, 4, 4, 4, 1, 4, 5, 1, 2, 4, 2, 5, 4, 4`

공식 정답표와 독립 재계산 결과가 일치했다.

## 주요 검수 사항

- **7번 - corrected**: 원문에 중력가속도 값이 명시되어 있지 않지만 공식 해설은 `g=10 m/s²`를 사용해 45 m를 얻는다. 보기와 공식 해설에 맞춰 사이트에서는 `g=10 m/s²` 조건을 명시해 적용했다. 정답은 ④이다.
- **19번 - corrected**: 원문은 얼음의 비열과 융해열만 제시하고 물의 비열을 명시하지 않았다. 공식 풀이와 통상 단위계를 따라 `c_water=1 kcal/(kg·°C)`를 사용하며 사이트 해설에 가정을 명시했다. 최종온도는 37.5°C, 정답 ④이다.
- **20번 - corrected**: 공식 해설 문장 중 ㄱ 설명이 실제 보기의 `B와 C 압력 비교`가 아니라 `A와 B 압력 비교`로 잘못 적혀 있다. T-V 그래프에서 `P_B=nRT/(4V)`, `P_C=2nRT/(4V)=2P_B`이므로 ㄱ은 참이다. B→C는 등적과정이라 Q=ΔU이고, 정답은 ④이다.
- **23번 - verified**: 원궤도 꼭대기의 최소조건 `v²=gR`과 마찰손실 `mgR`을 함께 적용하면 `h=7R/2`이다. 렌더링된 해설지의 식과 일치한다.
- **24번 - verified**: P-V 그래프에서 A 등압, B 등온, C 단열, D 등적이며 일의 크기는 `A>B>C>D=0`이다.
- **25번 - verified**: `Q_AB=3P0V0/2`, `Q_BC=15P0V0`, `Q_in=33P0V0/2`, 순환일 `W=3P0V0`이므로 `e=2/11`이다.

## 서술형 검증 답

- 21번: `T=v0 sinθ/g`, `H=v0² sin²θ/(2g)`, `R=v0² sin2θ/g`
- 22번: 완전탄성 `10√2 m/s`, e=0.4일 때 `2√29 m/s`
- 23번: `h=7R/2`
- 24번: `A 등압, B 등온, C 단열, D 등적`, `|W_A|>|W_B|>|W_C|>|W_D|=0`
- 25번: `e=2/11`

## 사이트 적용

모든 25문항에 검수된 해설, 공식, 자주 하는 실수, 4지/5지 원문 재도전 보기와 새 동형 객관식 문제를 등록했다. `corrected` 문항은 교정 메모를 함께 노출하고, 원문 문제 이미지와 원본·해설 PDF를 함께 연결한다.
