# 물리2심화 4회차 · 검수 및 로컬 시험 등록

기준: 사용자가 v3.7.6 증분 패치를 적용했다고 알린 이후 제공된 v3.7.6 전체 소스 ZIP. 실제 운영 GitHub SHA, Apps Script /exec, Google Sheets 현재 값은 **조회하지 않았음**. v3.7.7은 로컬 준비본.

## 문항·정답 검수

| 문항 | 배점 | 공식 해설과 검산 결과 | 주의 | 
|---|---:|---|---|
| 1 | 15 | R=(v₀²/g)(sin2θ+cos2θ−1), θ 최대=22.5° | 가속하는 대차 상대운동 |
| 2 | 10 | v₀²=4√3 gh | +30°와 −30°의 착지 시간 차 |
| 3 | 10 | n_max=2μMg/[mv(√3−μ)] | μ<√3, 1초 평균힘 모델; 실제 정수 n은 내림 처리 |
| 4 | 20 | t=2v₀sinθ/(gcosφ); d=2v₀²sinθcos(θ+φ)/(gcos²φ) | θ는 빗면에 대한 각 |
| 5 | 20 | A=v₀(sinθ−cosθtanα), t=[A+√(A²+2gh)]/g, s=v₀cosθ·t/cosα | 양의 시간해 사용 |
| 6 | 15 | V=−mv/(M+m), Δx=−mL/(M+m) | 대차는 왼쪽 |
| 7 | 10 | 첫 충돌 A=−5, B=+10; 둘째 B=−2, C=+8, A=−5 m/s | 탄성충돌 연속 적용 |
| **합계** | **100** | **7문항** | '초파 2점' 가산 미반영 |

원본 시험지 PDF(4p)와 원본 해설 PDF(5p)를 보존하였고, 독립 검수 해설(4p)을 웹사이트에 추가했습니다. 원본 해설 5쪽은 내용 없는 별도 페이지입니다.

## 등록 및 기존 기능 영향

- `physics2-advanced-r04`: 신규 시험 ID, `ready`, 서술형 7문항/100점.
- 교사 입력: 문항별 `1`=만점, `0`=오답, `P1`=1점, 실수 부분점수, 공란; 문항 순서와 100점 합 일치.
- 학생 분석: 문항별 정답, 공식, 흔한 실수, 채점 루브릭, 원문/동형 재도전 각각 7개 객관식(4지).
- 물리2심화 총괄(미준비)의 회차 누적 목록만 r02/r03/r04 확장; 다른 시험 정의는 내용 불변.
- 기존 물리1 16회차 구형/개정 분리(3m·2m 정정본), 물리2 일반 14회차와 학생 페이지/Word/PDF/카카오 미리보기 기능 보존.
- Apps Script, Cloudflare Worker, `pages.yml`, `runtime-config.js`, `share-config.js`, 개인정보/영구 링크 관련 코어 코드 변경 없음. Sheet 실데이터 조회·수정 없음.

## 배포 전 점검 및 롤백 (이번 작업에서 배포하지 않음)

1. 운영 GitHub 최신 커밋과 이번 v3.7.6 기준 ZIP의 차이부터 비교합니다. 현재 운영 상태는 사용자 진술만 있고 원격 검증은 미실시입니다.
2. `Courses`/`Exams`/`Questions`/`QuestionOverrides`와 학생 관련 `Students`/`Reports`/`StudentLinks`/병합 시트를 실제 존재하는 범위에서 백업하고 `physics2-advanced-r04` 중복 및 오버라이드 충돌을 검사합니다.
3. 사용자 **명시적 배포 승인 후** GitHub 파일에 v3.7.6→v3.7.7 패치 한 개를 적용하고 기존 학생 링크·문제 데이터 회귀 검증을 수행합니다.
4. 교사용에서 물리2심화 4회차가 `ready`, 7문항 100점으로 표시되는지, 실수 부분점수/오답/동형 각 7개가 정상이었는지 점검합니다.
5. 시험 설정 서버 동기화는 `Exams`·`Questions` 전체 교체 가능성이 있으므로 백업과 비교 후에만 별도 승인으로 수행합니다. 기존 학생 보고서·링크 변경 금지.
6. 문제 시 적용 전 GitHub 커밋으로 되돌립니다. 운영 시트에 변경이 발생했다면 백업 및 차분검증으로 복원하되 새 성적 행을 임의 삭제하지 않습니다.
