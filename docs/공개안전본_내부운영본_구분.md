# 공개안전본과 내부운영본 구분

## GitHub 공개 가능

- HTML, CSS, JavaScript
- 시험 카탈로그와 검증된 문항 데이터
- 원문 시험지·해설지와 문제 이미지: 배포 권한이 확보된 경우에만
- 설치 문서와 익명 예시 데이터
- 테스트 코드

## 공개 금지

- 실제 학생 이름, 학교, 학년, 점수
- Reports 시트 내보내기
- 학생 토큰과 지문
- WRITE_KEY
- FINGERPRINT_SECRET
- 비공개 Spreadsheet ID를 포함한 운영 메모

실제 학생 데이터는 Google Sheets에만 저장합니다. localStorage는 데모와 입력 복구에만 사용합니다.
