# Young’s Physics 로고·테마 리브랜딩 패치 내용

## 적용 대상

기존 **복습·총괄 통합판 2.0**의 기능과 학생 데이터를 유지하면서, 사용자가 제공한 공식 Young’s Physics 로고와 파란색 기반 디자인을 실제 프로젝트 파일에 적용하는 패치입니다.

## 화면 변경

- 교사용 화면: 브랜드 헤더, 과학형 히어로, 학생·시험 카드, 점수 링, 고정 저장 패널
- 학생 리포트: 브랜드 표지, 점수·평균 비교, 강점·보완 카드, 레이더 차트, 문항 분석, 오답 재도전
- 안내 화면: 동일 로고와 푸터 적용
- 모바일: 교사용·학생 리포트 모두 가로 넘침 제거

## Word 출력 변경

- 실제 OOXML DOCX 구조 유지
- 공식 로고, 비교 그래프, 레이더 차트, 문제 이미지 문서 내부 삽입
- 남색·파란색·흰색 중심의 표지와 표 디자인 적용
- 긴 문제 이미지 최대 크기 제한과 불필요한 빈 페이지 제거

## 문제 이미지 보정

- 물리1 역학 총괄 11~20번 렌더 페이지 연결 교정
- 물리1 역학·전자기/파동 21~25번 서술형의 큰 빈 답안 영역을 제외하도록 crop 보정
- 정답·해설·점수 데이터는 변경하지 않음

## 서버 영향

다음 파일과 데이터 구조는 이번 디자인 패치에서 변경하지 않습니다.

```text
apps-script/Code.gs
Google Sheets 시트 스키마
SPREADSHEET_ID / WRITE_KEY / FINGERPRINT_SECRET
기존 학생 토큰·지문
총괄–복습 연결 정책
```

따라서 기존 통합판 2.0에 이 패치만 적용할 때는 **GitHub Pages 재배포만 필요**하며 Apps Script 재배포와 시험 설정 서버 동기화는 필요하지 않습니다.

## 검증

- 자동 테스트 50/50 통과
- 데스크톱·모바일 브라우저 가로 넘침 없음
- console/page/failed request 오류 0개
- 원문 및 동형 문제 단계별 공개 정상
- DOCX A4 15페이지, 내부 이미지 13개, 외부 이미지 연결 0개
- PDF A4 15페이지
