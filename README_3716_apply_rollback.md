## 이번에 추가한 내용

기존 대기 시험 `physics2-basic-r03`를 활성화했습니다. 물리2 3회차, 중력장 내 운동, 서술형 8문항·100점입니다. 문항별 배점은 20/10/10/10/10/10/10/20점입니다. 1번은 5점씩 네 소문항이고 8번은 7/7/6점입니다. 문제지 하단의 초파 그림 2점은 기본 점수에 자동 가산하지 않습니다.

첨부 문제지·해설지 2쪽씩은 바이트 그대로 보존했습니다. 문제와 그림은 원본 PDF를 200dpi로 렌더링하여 직접 추출했습니다. 5·7번은 공통 지문·그림과 해당 문제의 원본 영역을 픽셀 변형 없이 연결하여, 각각 독립적으로 열어도 필요한 조건이 보입니다. 새로 그린 그림이나 재작성한 원문은 없습니다.

학생용 원문 객관식 재도전 8개, 새 동형 객관식 문제 8개, 해설, 공식, 단원별 분석을 연결했습니다. 재도전 해설은 답 제출 뒤 표시됩니다. 물리2 역학 총괄의 기존 누적 목록에 r03가 이미 있어 같은 기존 ID를 사용합니다.

교사 입력은 기존 방식 그대로입니다. `1`은 해당 문항 만점, `0`은 0점, `P1`은 실제 1점, 그 밖의 유효한 숫자는 부분점수, 공란은 미채점입니다. 실제 시험의 서술형 답안을 자동 채점하는 기능을 추가한 것은 아닙니다.

## 원본 해설에서 확인한 사항

2번은 문제의 충돌 직전 속력비 A:B=4:1을 적용하면 충돌 높이가 `3h/5`입니다. 원본 해설은 2:1을 대입하여 `2h/3`을 제시했습니다.

5번은 문제지대로 x·y 방향 속도 성분의 크기를 각각 묻는 것으로 등록했습니다. 정답은 10 m/s와 19.6 m/s입니다. 해설지 질문 문장은 전체 속력을 묻는 형태지만 해설에 적힌 두 성분 값은 맞습니다.

8-(1)은 높은 궤도 A의 체공시간이 더 길므로 `A>B`입니다. 원본 해설에는 반대로 적혀 있습니다. 8-(2)는 그림에서 `θ_A>θ_B`를 판단할 수 있지만, 두 각의 합이 90°라는 결론에는 같은 초기속력 조건이 필요합니다. 8-(3)의 공기저항 사거리 비교는 물체·초기속력·저항조건이 충분히 주어지지 않아 대소를 확정하지 않습니다. 배점은 문제지의 6점을 사용합니다.

원본 PDF는 수정하지 않았고, 사이트의 검산 해설과 `site/assets/documents/physics2/r03-reviewed-solution.pdf`에 정정 내용을 구분해 두었습니다. 자세한 내용은 `docs/physics2-basic-r03-review.md`를 참고하세요. 학생 화면의 원본 해설 PDF 링크는 첨부 원본을 엽니다. 교정된 텍스트 해설은 재도전 답 제출 뒤 표시됩니다.

## 적용 절차

1. 실제 운영 GitHub의 전체 소스와 정상 커밋, Google Sheets의 Students/Reports/Courses/Exams/Questions/QuestionOverrides를 먼저 백업합니다. 카탈로그 변경 후 로그인된 교사 화면을 열면 기존 자동 시험설정 동기화가 작동할 수 있으므로, 백업은 새로고침보다 먼저 합니다.
2. 패치 ZIP을 별도 폴더에 풉니다. 아직 기존 저장소에 덮어쓰지 않은 상태에서 다음 중 해당 기준의 검사만 실행합니다.


3. `PASS_BASE`일 때 해당 패치의 내부 파일들을 기존 저장소의 같은 상대 경로로 추가·덮어씁니다. `ALREADY_COMPLETE`면 재적용하지 않습니다. `STOP`이면 불일치가 있으므로 덮어쓰지 않습니다. 검사 스크립트는 파일·서버를 바꾸지 않는 읽기 전용입니다.
4. `npm test`를 실행합니다. 이 준비본의 결과는 총519개, 통과518개, 기존 학생 Excel 원본 미첨부로 1개 건너뜀, 실패0개입니다.
5. 명시적으로 배포하기로 한 때에만 기존 정적 사이트 배포 절차로 적용합니다. Apps Script·Worker 코드 교체나 재배포는 필요하지 않습니다. 설치함수 재실행, PIN 초기화, 링크 재발급, 학생자료 재생성은 하지 않습니다.
