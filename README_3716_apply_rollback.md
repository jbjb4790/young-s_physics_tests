# Young's Physics v3.7.16 · 일반 물리2 3회차 복습테스트

첨부된 「물리2-개념정리Quiz 3회차.pdf」와 「물리2-개념정리Quiz 3회차 해설.pdf」를 기존 일반 물리2 3회차 항목에 등록한 소스 패치입니다. 시험 ID `physics2-basic-r03`를 유지하며 새 시험 슬롯을 중복 생성하지 않습니다. 이 파일은 로컬에서 제작·검증한 배포 준비본이며 운영 사이트에 아직 반영하지 않았습니다.

## 적용할 파일

현재 저장소에 v3.7.15가 적용되어 있으면 `YP3716_patch_from3715.zip`을 사용합니다.

현재 저장소가 v3.7.13이면 `YP3716_cumulative_from3713.zip`을 사용합니다. 누적 패치는 심화 물리2 6회차의 최종 교체 원본, 일반 물리2 2회차와 이번 3회차를 함께 포함합니다. 두 패치를 함께 적용할 필요는 없습니다.

`YP3716_FULL_SOURCE.zip`은 전체 소스 보관용입니다. 운영 저장소의 배포 설정을 보존하기 쉽도록 해당 버전의 증분·누적 패치를 우선 사용합니다. 위 두 기준에 맞지 않는 저장소에 패치를 억지로 적용하지 마십시오.

## 등록 내용과 배점

문제지와 해설지는 각각 1쪽이며 원본 PDF를 바이트 변경 없이 포함했습니다. 원문 문제·수식·선택지는 200dpi로 렌더링한 원본 페이지에서 직접 잘라 사용합니다. 문제 내용을 새로 그리거나 재조판하지 않았습니다.

원본 번호는 유형마다 다시 1번으로 시작합니다. 사이트에서는 빈칸 1~4를 웹 1~4번, O/X 1~6을 웹 5~10번, 암기 1~6을 웹 11~16번으로 등록했습니다. 문항 주제에 원래 유형과 번호를 병기했습니다.

**원본에는 배점이 없습니다.** 기존 100점 체계에 맞춰 20개 답란에 각각 5점을 부여했습니다. 웹 1~10번은 각각 5점, 웹 11~16번은 차례대로 10·5·10·10·10·5점입니다. 식을 두 개 쓰는 문항은 각 식에 5점씩 부여합니다. 화면 안내와 채점 기준에 이 배점이 사이트 환산이라는 점을 표시했습니다.

제공 해설의 정답은 표준 조건에서 모두 맞습니다. 공기 저항 무시, 일정한 중력가속도, 같은 발사·착지 높이, 좌표축의 방향과 같은 적용 조건은 답을 먼저 보여 주지 않는 안내와 웹 풀이에 보완했습니다. 원본 해설의 마지막 `45`는 웹에서 `45°`로 표기했습니다. 원본 해설 PDF 자체는 수정하지 않았습니다.

원문 재도전 16개와 별도로 작성한 동형 문제 16개를 기존 4지선다 방식으로 연결했습니다. 원본 해설은 PDF 링크로 제공하고, 각 문항에는 정답·검수 풀이·공식·오답 포인트·채점 기준을 넣었습니다.

## 교사 성적 입력

기존 주간 복습테스트 규칙을 그대로 사용합니다. `1`은 해당 문항 만점, `0`은 0점, `P1`은 실제 1점, 그 밖의 유효한 숫자는 실제 부분점수이며 공란은 미채점입니다. 예를 들어 10점짜리 공식 문항에서 두 식 중 하나만 맞으면 `5`를 입력합니다.

이 자료의 O/X는 **문제 유형**입니다. 교사용 성적 입력칸에는 학생의 답인 O 또는 X를 넣지 않고, 채점 결과에 맞게 `1` 또는 `0`을 입력합니다. CSV도 Q1~Q16 순서의 성취값을 사용합니다. `sample-data/physics2-basic-r03-example.csv`의 학생들은 형식 확인용 가상 예시입니다.

## 적용 순서

1. 배포하거나 로그인된 교사 페이지를 다시 열기 전에 실제 운영 GitHub 소스와 Google Sheets의 `Students`, `Reports`, `Courses`, `Exams`, `Questions`, `QuestionOverrides`를 백업합니다. 변경된 카탈로그가 감지되면 기존 교사 페이지가 서버 설정을 자동 동기화할 수 있으므로 먼저 백업합니다.
2. 패치를 별도 폴더에 풀고 `python CHECK_3716.py 현재_전체소스.zip` 또는 `python CHECK_3716.py 현재_소스폴더`로 호환성을 확인합니다. 읽기 전용 검사이며 서버에 접속하거나 파일을 수정하지 않습니다. `PASS_BASE`이면 출력된 기준 버전에 맞는 ZIP을 적용합니다. `ALREADY_COMPLETE`이면 이번 핵심 파일이 이미 적용된 상태입니다. `STOP`이면 다른 기준 버전 또는 사용자 수정본이므로 덮어쓰지 않습니다.
3. ZIP 자체를 GitHub에 한 파일로 업로드하는 방식이 아닙니다. 압축을 풀고 `site/`, `tests/` 등 내부 파일을 기존 저장소의 동일한 상대 경로에 추가·덮어씁니다. 기존 다른 파일을 삭제하지 않습니다. 패치에는 운영 Apps Script 주소, 교사 PIN, 학생 데이터 또는 배포 설정을 교체하는 변경이 없습니다.
4. 가능하면 저장소에서 `npm test`를 실행합니다. 이 준비본의 검증 결과는 총 516개 중 515개 통과, 기존 179명 Excel 자료 미첨부로 1개 건너뜀, 실패 0개입니다.
5. 기존 GitHub Pages 절차로 배포하고 교사 페이지를 새로고침합니다. `물리2 → 3회차`에서 16문항·100점, 원본 문제·해설 링크, 각 문항 배점을 확인합니다. 로그인된 교사 화면의 자동 동기화가 끝났는지 확인하며, 저장소에서 별도 수정해 둔 `QuestionOverrides`가 있으면 신규 시험 설정과 충돌하는지만 확인합니다. Apps Script와 Worker의 코드 변경·재배포는 필요하지 않습니다.

## 보존 사항과 되돌리기

v3.7.15 대비 다른 46개 시험 정의와 기존 31개 문항은행 JSON은 그대로입니다. 학생 ID, 영구 링크와 지문 생성, 성적 저장·조회, 반별 이름 검색, 학생 학교 변경, 서버 코드와 배포 설정은 변경하지 않았습니다. 물리2 역학 총괄의 누적 분석 목록에는 3회차가 이미 포함되어 있어 해당 목록도 유지했습니다.

이번 시험의 성적을 아직 저장하지 않았다면 적용 직전 정적 소스 커밋으로 되돌릴 수 있습니다. 이미 3회차 성적을 저장했다면 새 시험 정의와 PDF·이미지 및 해당 Reports 행을 보존한 상태에서 복구해야 합니다. 기존 Students·Reports 전체를 삭제하거나 과거 시트로 덮어쓰지 않습니다. 토큰 재발급, PIN 재설정, 초기 설치 함수 실행은 필요하지 않습니다.

원본 PDF 렌더링과 16개 문항 크롭을 시각 확인했고, 프로그램 검사와 패치 재적용 검증을 수행했습니다. 실행 환경에서 Chromium 실행이 제한되어 실제 브라우저 화면 조작·운영 서버 연결 검증은 수행하지 못했습니다. 운영 배포 완료로 간주하지 않습니다.
