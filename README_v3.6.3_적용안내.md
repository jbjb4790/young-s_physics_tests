# Young’s Physics v3.6.3 적용 안내

## 변경 목적
총괄평가 페이지에서 현재 시험 한 번의 점수만으로 코멘트를 만들지 않고, 학생에게 이미 누적된 복습·총괄 기록을 함께 반영해 학부모용 학습 코멘트를 자동 작성합니다.

## 코멘트에 반영되는 데이터
- 현재 총괄평가 점수와 동일 평가 전체 평균
- 상위 50% 이내일 때 기존 상위 N% 정보
- 해당 총괄평가와 연결된 복습 테스트 회차 수
- 최근 복습 성취 흐름: 상승 / 안정 / 하락
- 복습 누적과 현재 총괄에서 반복되는 강점 단원
- 반복적으로 낮게 나타나는 우선 보완 단원
- 복습 대비 이번 총괄에서 개선된 단원
- 현재 총괄의 오답 및 부분점수 문항

학생 통합 페이지에서 비공개 처리한 `누적 가중 성취율` 숫자는 코멘트에도 노출하지 않습니다.

## 적용 순서
1. 현재 GitHub 저장소를 백업합니다.
2. `YoungsPhysics_총괄누적코멘트_v3.6.3_GitHub패치.zip`을 압축 해제합니다.
3. 압축 내부 파일을 저장소 최상위에 경로 그대로 덮어씁니다.
4. 커밋 후 기존 GitHub Pages workflow가 완료될 때까지 기다립니다.
5. 교사용 사이트와 학생 통합 페이지를 `Ctrl + Shift + R`로 강력 새로고침합니다.
6. 학부모용 학생 영구 링크에서 `총괄평가` 탭을 엽니다.
7. 총괄평가 탭 상단의 `누적 데이터 기반 학습 코멘트`와 각 총괄평가 상세의 코멘트를 확인합니다.

## Apps Script
이번 버전은 Apps Script와 Google Sheets 스키마를 변경하지 않습니다.
따라서 아래 작업은 필요하지 않습니다.
- Code.gs 교체
- appsscript.json 변경
- 웹 앱 새 버전 배포
- installYoungsPhysics() 실행
- 학생 포털 마이그레이션
- 시험 설정 서버 동기화
- 학생 링크 재발급

## 코멘트 갱신
학생 시험 결과가 새로 저장되거나 기존 결과가 수정·삭제되면, 학부모가 페이지를 다시 열 때 최신 누적 데이터를 기준으로 코멘트가 다시 계산됩니다.
