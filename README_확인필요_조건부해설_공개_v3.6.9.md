## 공개 방식

원문 보충 조건은 문제 카드 위에 먼저 표시되고, 학생이 객관식 원문 재도전에 **답을 제출한 뒤** 검증된 해설과 동형문제가 공개됩니다. 이 기능은 단지 배포 카탈로그의 검수 상태와 보충 해설을 수정한 것으로 기존 학생 점수/영구 링크/교사 PIN은 변경되지 않습니다.

> 위 조건은 원본 시험의 실제 조건이었다는 뜻이 아닙니다. 원본 시험 문항의 공식 채점 기준에 영향을 미치려면 교사가 별도 확정해야 합니다.

## 적용

기존 저장소에서는 제공된 GitHub 패치를 압축 해제하여 경로대로 덮어쓴 후 커밋·Pages 배포하고, 교사 인증 후 **시험 설정 서버 동기화**를 실행하세요. Apps Script Code.gs 및 웹 앱 재배포는 필요 없습니다. Google Sheets QuestionOverrides에 교사가 수정한 정답이 있을 경우 해당 수정본이 우선됩니다.
