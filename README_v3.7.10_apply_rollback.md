# Young’s Physics v3.7.10 적용·되돌리기 안내

2026-11-07 / 정상 v3.7.9 소스 기준 / 운영 미배포

## 변경 목적과 범위

물리2심화 4회차의 새 4·5번을 **별도 시험 ID** `physics2-advanced-r04-v2`에 등록합니다. 기존 `physics2-advanced-r04`의 모든 문항·문제 PDF·해설·이미지·원문/동형 재도전은 그대로 유지합니다. 기존 저장 기록의 ID를 바꾸거나 학생 점수를 새 기준으로 재채점하는 마이그레이션은 없습니다.

일반 교사 시험 선택에는 새 `4회 복습 테스트 (개정)`이 보입니다. 기존 학생 여부와 무관하게 새 4회차 성적은 개정판으로 입력합니다. 이미 저장된 구형 기록의 ‘수정’은 구형을 유지합니다. 수정 취소·신규 학생·학생 전환 시에는 개정판으로 복귀합니다. 구형 편집 화면에서 일괄 가져오기를 시작하면 개정판으로 전환하고 새 시험 결과 파일 재선택을 요구합니다. 구형의 일괄 저장은 차단하며 기존 기록은 개별 수정으로 관리합니다.

같은 학생이 구형과 개정판 둘 다 응시했다면 두 개별 성적표를 모두 보존합니다. 기존 통합 포털의 전체 시험 수는 실제 두 기록을 유지합니다. 심화 총괄의 연결 복습 분석에서는 같은 4회차를 중복 집계하지 않고 개정판을 우선합니다. 구형 기록만 있으면 구형 분석을 유지합니다. 총괄 시험은 원래의 자료 준비 상태를 유지합니다.

7문항·100점, 배점 15·10·10·20·20·15·10은 동일합니다. 첨부 해설 기준 4번은 d=5 m, t=1 s, 5번은 t=2 s, s=10 m입니다. 4번의 θ=60°는 첨부 해설의 수평·수직 좌표식에 맞춰 수평선 기준입니다. 원문 해설에서 혼용된 좌표축 설명·소문항 번호와 5번 궤적식의 +10 누락은 별도 검수 보충으로 구분하며 원본 PDF는 수정하지 않습니다.

## 적용 전 필수 확인

실제 운영 GitHub 커밋, v3.7.5 누락 복구 적용 여부, v3.7.8·v3.7.9의 실제 적용 여부, Apps Script `/exec`, Google Sheets 최신 값은 이번 로컬 작업으로 확인하지 않았습니다. 이 패치는 **정상 v3.7.9 전용 증분**입니다. 운영 최신 소스를 내려받아 비교해야 하며, 이전 버전이나 별도 변경이 있으면 덮어쓰지 않습니다. 과거 v3.7.5 패치를 나중에 다시 덮어쓰지 마세요.

현재 GitHub 소스 ZIP 또는 로컬 소스 폴더를 대상으로 아래 명령을 실행합니다. 이 도구는 원격 요청·쓰기·배포 없이 파일 해시만 읽습니다.

```bash
python CHECK_PATCH_v3.7.10.py CURRENT_REPOSITORY.zip
# 또는
python CHECK_PATCH_v3.7.10.py /path/to/current/repository
```

`PASS`는 로컬 소스 일치만 뜻하며 실제 배포/학생 데이터 검증 완료라는 뜻이 아닙니다. `STOP` 또는 `ERROR`이면 적용을 멈춥니다. 신규 파일이 이미 존재하되 내용이 다르면 충돌로 중단합니다. 검사 도구와 매니페스트를 같은 폴더에 두세요.

**배포와 로그인된 교사 화면 재접속 전에 Google Sheets 사본을 먼저 백업하세요.** 기존 `app.js`가 카탈로그 변경을 감지하면 `autoSyncCatalog(false)`로 시험 설정을 자동 동기화할 수 있습니다. 수동 동기화 버튼을 누르기 전에도 동기화될 수 있습니다.

백업/검토 대상은 Students, Reports, Courses, Exams, Questions, QuestionOverrides 및 반·병합 관련 시트입니다. 구형 `physics2-advanced-r04` 문항·정답 수정값은 보존해야 하고, 개정 ID가 운영에서 이미 사용 중이면 먼저 충돌을 해소해야 합니다. 원격 운영에서 구형 문항 자체를 직접 수정한 적이 있으면 로컬 정본과 다를 수 있으므로 무작정 동기화하지 않습니다. 기존 서버 syncCatalog는 Courses/Exams/Questions를 교체하고 QuestionOverrides를 별도로 유지합니다. 구형 override를 개정판 ID로 복사하지 마세요.

## 적용 순서

1. 교사 화면을 닫고 운영 GitHub 최신 커밋/전체 소스와 Sheets 사본을 백업합니다.
2. 사전검사와 두 시험 ID의 Questions/QuestionOverrides 충돌 검토를 완료합니다.
3. 패치 ZIP의 상대 경로대로 파일을 추가·교체합니다. 폴더를 한 단계 더 감싸서 업로드하지 않습니다. 삭제 파일은 없습니다.
4. `npm test`를 실행하고 396개 중 395 통과·1 건너뜀·0 실패를 확인합니다. 건너뜀은 기존 학생 Excel 원본 미첨부 테스트입니다.
5. 사용자가 승인한 GitHub Pages 배포 후 강력 새로고침합니다. Apps Script/Worker는 변경하거나 재배포하지 않습니다. 기존 `/exec` 주소와 배포 설정을 유지합니다.
6. 구형 가상/시험용 기록 조회·수정, 신규 개정판 입력, 동일 학생 영구 링크, 구형/개정판 분석·문제 이미지·재도전을 확인합니다. 기존 15회차와 총괄 성적표 버튼도 확인합니다.
7. 시험 설정 자동 동기화가 완료되었는지 확인한 뒤, 필요한 경우에만 백업·충돌 검토 후 수동 동기화를 실행합니다.

## 되돌리기

로그인된 교사 화면을 먼저 닫고 마지막 정상 커밋으로 되돌립니다. 기존 Apps Script와 Worker는 바뀌지 않았으므로 별도 재배포가 필요하지 않습니다. 이전 카탈로그로도 자동 동기화가 발생할 수 있으므로 다시 열기 전에 서버 시험 설정을 점검합니다.

**개정판 성적이 하나라도 생긴 뒤에는 개정 시험 ID·PDF·Questions를 삭제하는 단순 롤백을 하지 않습니다.** 새 Reports/Students/QuestionOverrides와 개정판 자료를 보존한 상태에서 UI 변경만 되돌리거나 고친 패치를 사용합니다. 백업 이후 입력된 성적이 사라질 수 있으므로 Google Sheets 전체를 과거 백업으로 덮어쓰지 않습니다.

학생 ID·포털 토큰·지문·시험 토큰을 재발급하거나 시험 ID를 강제 변환하지 않습니다. `installYoungsPhysics()`, `repairReportStorage()`, PIN 재설정, 학생 병합/마이그레이션을 실행하지 않습니다.
