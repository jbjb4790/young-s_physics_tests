# Young’s Physics v3.5.0 학생 영구 통합 포털 적용 안내

## 1. 변경 목적

학생 한 명에게 학부모용 링크를 하나만 발급하고, 이후 같은 학생에게 저장되는 주간 복습 테스트와 총괄평가 결과를 그 링크에 계속 누적한다.

학부모 페이지는 다음 탭으로 구성된다.

- 누적 요약
- 주간 복습
- 총괄평가
- 오답 학습

각 시험 카드를 누르면 같은 페이지 안에서 해당 시험의 점수, 동일 시험 평균, 상위 비율, 문항별 분석, 검수 해설, 객관식 원문 재도전과 객관식 동형 문제를 확인할 수 있다.

## 2. 업데이트 전 백업

1. 운영 중인 Google Spreadsheet에서 `파일 → 사본 만들기`를 실행한다.
2. 현재 Apps Script `Code.gs`를 별도 파일로 보관한다.
3. GitHub 저장소의 현재 상태를 커밋하거나 ZIP으로 내려받아 보관한다.

기존 `Reports`, `Questions`, `QuestionOverrides` 시트를 삭제하지 않는다.

## 3. Apps Script 적용

### 3.1 Code.gs 교체

운영 Google Spreadsheet에서 다음으로 이동한다.

```text
확장 프로그램 → Apps Script → Code.gs
```

1. 기존 `Code.gs` 내용을 모두 삭제한다.
2. `YoungsPhysics_학생통합포털_v3.5.0_Code.gs`의 내용을 전체 붙여넣는다.
3. 저장한다.

새 OAuth 권한을 추가하지 않으므로 기존 `appsscript.json`이 정상이라면 다시 바꿀 필요가 없다.

다음 함수는 실행하지 않는다.

```text
installYoungsPhysics()
resetTeacherPin()
repairReportStorage()
```

### 3.2 웹 앱 새 버전 배포

```text
배포 → 배포 관리 → 기존 웹 앱 편집 → 버전: 새 버전 → 배포
```

기존 설정을 유지한다.

```text
실행 사용자: 나
액세스 권한: 모든 사용자
```

기존 배포를 새 버전으로 갱신하면 일반적으로 `/exec` 주소는 유지된다. 주소가 유지되면 GitHub의 Apps Script URL 설정은 수정하지 않는다.

## 4. 기존 시험 기록을 학생 영구 링크에 연결

Apps Script 함수 목록에서 다음 함수를 실행한다.

```text
migrateStudentPortals
```

한 번에 최대 300개 시험 기록을 처리한다. 실행 로그의 결과가 다음처럼 `done:false`이면 다시 실행한다.

```json
{
  "ok": true,
  "done": false,
  "processed": 300,
  "remainingRows": 125
}
```

다음처럼 `done:true`가 나오면 완료이다.

```json
{
  "ok": true,
  "done": true,
  "remainingRows": 0
}
```

마이그레이션 과정에서 다음 변화가 생긴다.

- `Students` 시트가 생성된다.
- `Reports` 시트 끝에 `StudentId` 열이 추가된다.
- 기존 점수와 시험별 토큰·지문은 유지된다.
- 기존에 전달한 개별 시험 링크도 계속 사용할 수 있다.
- 학생별 영구 포털 토큰과 지문이 새로 발급된다.

진단이 필요하면 다음 함수를 실행한다.

```text
diagnoseStudentPortals
```

`reportsWithoutStudentId`가 0이면 모든 기존 기록이 학생 프로필에 연결된 상태이다.

## 5. GitHub 패치 적용

`YoungsPhysics_학생통합포털_v3.5.0_GitHub패치.zip`을 컴퓨터에서 압축 해제한다.

압축 내부 파일과 폴더를 GitHub 저장소 최상위에 경로 그대로 덮어쓴다. ZIP 파일 자체를 저장소에 올리지 않는다.

권장 패치에는 다음 파일이 포함되지 않는다.

```text
.github/workflows/pages.yml
site/assets/runtime-config.js
```

따라서 현재 정상 동작 중인 GitHub Pages workflow와 Apps Script `/exec` 주소 설정은 그대로 유지된다.

커밋 메시지 예시:

```text
Add permanent student portal with cumulative results v3.5.0
```

커밋 후 기존 GitHub Pages Actions가 성공하는지 확인한다.

## 6. 브라우저 새로고침

GitHub Pages 배포가 끝난 뒤 교사용 사이트를 강력 새로고침한다.

```text
Windows: Ctrl + Shift + R
Mac: Command + Shift + R
```

## 7. 교사용 화면 사용법

### 7.1 기존 학생에게 시험 결과 추가

1. 과정과 시험을 선택한다.
2. `기존 학생 연결`에서 학생을 선택한다.
3. 점수 또는 학생 선택번호를 입력한다.
4. `저장·성적 분석·학생 링크 복사`를 누른다.

저장 완료 후 복사되는 링크는 이번 시험만 보는 링크가 아니라 그 학생의 영구 통합 링크다. 이후 같은 학생의 다른 시험을 저장해도 링크는 바뀌지 않는다.

### 7.2 동명이인 신규 학생

같은 학교에 같은 이름의 다른 학생을 추가할 때는 다음을 누른다.

```text
동명이인 신규 학생
```

가능하면 학년, 반·번호 또는 외부 학생 ID를 입력해 구분한다.

### 7.3 학생별 영구 링크 관리

교사용 홈페이지의 `학생 통합 링크` 영역에서 다음을 할 수 있다.

- 학생별 누적 시험 수 확인
- 누적 평균과 최근 시험 확인
- 영구 링크 복사
- 영구 페이지 열기
- 학생 프로필 선택 후 새 시험 저장

## 8. 학부모 페이지 구성

### 누적 요약

- 누적 가중 성취율
- 시험별 평균 성취율
- 최근 성취율
- 주간 복습·총괄평가 응시 수
- 누적 오답·부분점수 수
- 성취 추이
- 단원별 누적 성취도
- 강점·보완 단원
- 최근 시험 목록

### 주간 복습

학생에게 연결된 모든 주간 복습 테스트를 시간순으로 확인한다.

### 총괄평가

학생에게 연결된 모든 총괄평가를 확인한다. 상위 50% 이내인 경우 동일 평가 내 상위 비율도 표시한다.

### 오답 학습

모든 시험의 0점·부분점수 문항을 한 번에 모아 확인한다.

### 시험 상세

시험 카드를 누르면 같은 페이지에서 다음 내용을 확인한다.

- 시험 점수와 동일 시험 평균
- 문항별 획득 점수와 전체 평균
- 단원별 강점·보완 영역
- 원문 문제 이미지
- 검수 해설·공식·자주 하는 실수
- 객관식 원문 재도전
- 객관식 동형 문제
- 기존 전체 성적표와 Word 출력 링크

## 9. 링크 보안

학생 영구 링크는 다음을 함께 검증한다.

- 학생 포털 토큰
- 학생 포털 지문
- 학생 식별 다이제스트
- 선택한 시험 기록이 해당 학생에게 속하는지 여부

다른 학생의 시험 토큰을 주소에 임의로 넣어도 해당 학생 소유 기록이 아니면 상세 결과가 열리지 않는다.

## 10. 최종 점검

1. 기존 학생 한 명을 선택해 새 시험 결과를 저장한다.
2. 저장 후 복사된 학생 영구 링크를 시크릿 창에서 연다.
3. 누적 요약, 주간 복습, 총괄평가, 오답 학습 탭을 확인한다.
4. 시험 카드 하나를 눌러 상세 분석과 재도전 보기를 확인한다.
5. 다른 시험 결과를 같은 학생에게 추가한다.
6. 앞에서 받은 동일 링크를 다시 열어 시험이 추가되었는지 확인한다.
7. 다른 컴퓨터에서 동일 링크가 정상적으로 열리는지 확인한다.
8. 동명이인 학생은 서로 다른 영구 링크를 받는지 확인한다.
