# Young’s Physics v3.4.4 적용 안내

## 1. 변경 목적

학생이 오답·부분점수 문항을 다시 풀 때 단답형·서술형 답안을 수식이나 문장으로 직접 입력하지 않고, 원문 문제는 그대로 보면서 4지 또는 5지 객관식 보기에서 답을 선택하도록 변경한다. 새 동형 문제도 모두 객관식으로 제공한다.

## 2. 변경 범위

- 준비 완료 시험: 9개
- 등록 문항: 108문항
- 서술형·단답형: 65문항
- 객관식: 43문항
- 원문 재도전 객관식 구성: 108/108
- 동형 문제 객관식 구성: 108/108
- 각 보기 수: 4개 또는 5개
- 선택 전 정답·해설 비공개
- 원문 답 제출 후 검수 해설 공개 및 동형 문제 활성화
- 동형 답 제출 후 정답·전체 풀이 공개

`ambiguous` 또는 `needs-review` 상태인 문항은 기존 운영 원칙대로 자동 정답 공개를 보류한다. 현재 해당 문항은 물리1 3회 7번과 물리1 5회 6번이다.

## 3. 적용 전 백업

1. 운영 Google Spreadsheet에서 `파일 → 사본 만들기`로 백업한다.
2. GitHub 저장소의 현재 `main` 브랜치를 별도 브랜치 또는 ZIP으로 백업한다.
3. Apps Script의 기존 `Code.gs`도 별도 파일로 보관한다.

## 4. Apps Script 적용

1. 운영 Spreadsheet에서 `확장 프로그램 → Apps Script`를 연다.
2. 기존 `Code.gs` 내용을 모두 삭제한다.
3. `YoungsPhysics_오답재도전_전문항객관식_v3.4.4_Code.gs` 전체를 붙여넣고 저장한다.
4. 다음 함수는 실행하지 않는다.

```text
installYoungsPhysics()
resetTeacherPin()
repairReportStorage()
```

5. `배포 → 배포 관리 → 기존 웹 앱 편집 → 버전: 새 버전 → 배포` 순서로 재배포한다.
6. 실행 사용자는 `나`, 액세스 권한은 기존 운영 설정인 `모든 사용자`를 유지한다.
7. 기존 배포를 새 버전으로 갱신했다면 `/exec` 주소는 보통 유지되므로 GitHub의 API URL을 다시 바꿀 필요가 없다.
8. `appsscript.json` 권한은 변경되지 않았으므로 기존 파일이 정상이라면 교체하지 않아도 된다.

v3.4.4 `Code.gs`는 Google Sheets `QuestionOverrides`에 남은 구형 자유입력·불완전 보기 설정을 그대로 병합하지 않는다. 4지·5지 객관식 조건을 만족하는 수정본만 사용하고, 그렇지 않으면 배포된 검수 원본 보기로 자동 복귀한다.

## 5. GitHub 적용

1. `YoungsPhysics_오답재도전_전문항객관식_v3.4.4_GitHub패치.zip`을 컴퓨터에서 압축 해제한다.
2. ZIP 내부 파일·폴더를 GitHub 저장소 최상위에 경로 그대로 덮어쓴다.
3. ZIP 자체를 저장소에 올리지 않는다.
4. 이 패치에는 다음 파일이 포함되지 않으므로 현재 정상 운영 설정이 유지된다.

```text
.github/workflows/pages.yml
site/assets/runtime-config.js
```

5. 권장 커밋 메시지:

```text
Convert all wrong-answer retries and similar problems to multiple choice v3.4.4
```

6. 커밋 후 기존 GitHub Pages Actions가 성공할 때까지 기다린다.
7. 배포 사이트에서 강력 새로고침한다.

```text
Windows: Ctrl + Shift + R
Mac: Command + Shift + R
```

## 6. 시험 설정 서버 동기화

교사용 홈페이지에서 교사 인증 후 다음을 한 번 실행한다.

```text
시험 설정 서버 동기화
```

이 작업은 Google Sheets `Questions` 시트의 원문 재도전·동형 문제 보기 데이터를 v3.4.4 카탈로그와 맞춘다. `QuestionOverrides`에 저장된 유효한 4지·5지 수정본은 유지된다.

## 7. 기능 확인

물리1 역학 총괄평가에서 서술형 21번을 틀린 테스트 학생을 만든 뒤 확인한다.

1. 학생 성적표 링크를 연다.
2. 21번 원문 문제와 문제 그림이 표시되는지 확인한다.
3. 자유 입력칸 없이 4개의 보기 카드가 표시되는지 확인한다.
4. 보기 선택 전 정답·해설이 보이지 않는지 확인한다.
5. 답을 제출하면 선택한 보기와 정답 보기가 구분되는지 확인한다.
6. 검수 해설·공식·부분점수 기준이 공개되는지 확인한다.
7. 동형 문제가 활성화되고 객관식 보기로 표시되는지 확인한다.
8. 동형 답 제출 후 정답·해설이 공개되는지 확인한다.
9. 모바일 화면에서 보기 카드가 한 열로 정렬되는지 확인한다.
10. Word 출력에서 원문 재도전 보기와 동형 문제 보기가 함께 포함되는지 확인한다.

## 8. 기존 학생 링크와 점수

이번 변경은 오답 학습 인터페이스와 문제 데이터를 바꾸는 작업이다. 기존 학생 점수·토큰·지문·학부모 링크는 유지된다. 학생 링크를 다시 열면 최신 객관식 재도전 화면이 표시된다.

정답 자체를 홈페이지 정답 관리에서 바꾼 경우에는 이미 저장된 학생 점수가 자동 재채점되지 않으므로, 동일 Excel을 다시 저장하거나 해당 학생 기록을 수정해야 한다.
