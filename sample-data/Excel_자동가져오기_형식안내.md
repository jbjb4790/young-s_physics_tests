# Excel·CSV 자동 가져오기 형식 안내 — v3.4.2

## 1. 일반·심화 총괄평가 입력 규칙

일반 물리1·물리2 총괄은 1~20번에 **학생이 실제로 고른 객관식 번호 1~5**, 21~25번에 실제 획득 점수를 입력합니다. 물리1심화·물리2심화 총괄은 1~25번 모두 학생 선택번호 1~5를 입력합니다.

```text
일반 물리1·물리2 총괄
Q1~Q20  → 학생 선택번호 1, 2, 3, 4, 5
Q21~Q25 → 실제 획득 점수 0~문항 배점

물리1심화·물리2심화 총괄
Q1~Q25  → 학생 선택번호 1, 2, 3, 4, 5
```

기존 0/1 또는 O/X 파일도 구형 정오표로 감지해 불러올 수 있지만, 새로 작성하는 파일에는 학생 선택번호를 사용합니다.

## 2. 첨부 역학 총괄평가 결과표 형식

시스템은 다음 구조를 자동 인식합니다.

```text
문제번호 행: 1, 2, 3, ... 25
학생 정보 행: 이름, 학년, 반, 학원, 전반부, 후반부, 총점, 시험일시
일반 총괄 1~20번: 학생이 선택한 답 번호 1~5
일반 총괄 21~25번: 실제 획득 점수
심화 총괄 1~25번: 학생이 선택한 답 번호 1~5
```

학교 열이 없으면 학교는 `미기입`으로 저장됩니다. `학원` 열은 학교가 아니므로 학교에 복사하지 않습니다.

## 3. CSV 이름 열과 문항 열

이름 열은 다음 헤더 중 하나를 사용할 수 있습니다.

```text
이름, 성명, 학생명, 학생 이름, 학생, Name, StudentName
```

문항 열은 다음 형식을 지원합니다.

```text
Q1, Q2, ... Q25
1번, 2번, ... 25번
문항1, 문항2, ... 문항25
문제1, 문제2, ... 문제25
1, 2, ... 25
```

헤더가 첫 줄이 아니어도 앞부분 약 35행을 검색합니다. 문제번호 행과 이름 헤더 행이 나뉜 결과표도 인식합니다.

## 4. CSV 문자 인코딩과 구분자

다음 형식을 자동 감지합니다.

- UTF-8 및 UTF-8 BOM
- CP949/EUC-KR
- UTF-16 LE/BE
- 쉼표, 탭, 세미콜론 구분자

따라서 한글 Excel에서 `CSV(쉼표로 분리)`로 저장한 CP949 파일도 별도 변환 없이 첨부할 수 있습니다.

## 5. 표준 CSV 예시

```csv
학교,성명,학년,반번호,Q1,Q2,Q3,Q4,Q5,...,Q20,Q21,Q22,Q23,Q24,Q25
,홍길동,2,,5,2,3,5,1,...,2,4,3,2,1,0
```

- 학교 빈칸 → `미기입`
- Q1~Q20 → 학생 선택번호
- Q21~Q25 → 실제 점수

## 6. 가져오기 절차

1. 사이트에서 과정과 총괄평가를 먼저 선택합니다.
2. `.xlsx` 또는 `.csv` 파일을 `Excel·CSV 일괄 입력` 영역에 첨부합니다.
3. 인식된 이름 열, 학생 수, 문자 인코딩, 학교 미기입 인원, 재계산 점수를 확인합니다.
4. 오류가 없는 학생만 `검증된 학생 기록 일괄 저장`으로 저장합니다.

## 7. 같은 파일을 다시 올릴 때

동일한 시험·학교·학생 이름의 기록이 있으면 새 학생을 만들지 않고 기존 기록을 수정합니다. 기존 학생 토큰과 학부모 링크는 유지됩니다.

## 8. 지원 제한

- Excel은 `.xlsx`를 지원합니다. 구형 `.xls`는 `.xlsx` 또는 CSV로 다시 저장하세요.
- 암호화 또는 비밀번호가 걸린 Excel은 지원하지 않습니다.
- 실제 학생 파일은 GitHub 저장소에 올리지 마세요.
- Excel·CSV 원본 파일은 브라우저에서만 읽고, 정규화된 학생 기록만 Apps Script로 전송합니다.
