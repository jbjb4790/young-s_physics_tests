# Young’s Physics v3.5.0 학생 영구 통합 포털

## 목표

학생 한 명에게 한 개의 학부모용 영구 링크를 발급하고, 이후 저장되는 모든 주간 복습 테스트와 총괄평가를 같은 페이지에 누적한다.

## 학부모 페이지

- 누적 요약: 가중 성취율, 시험 평균, 최근 성취율, 누적 오답, 성취 추이, 강점·보완 단원
- 주간 복습: 회차별 점수와 분석
- 총괄평가: 파트별 총괄 점수, 동일 평가 평균과 상위 비율
- 오답 학습: 모든 시험의 오답·부분점수 문항 모음
- 시험 상세: 같은 페이지에서 문항별 점수·평균, 검수 해설, 원문 객관식 재도전, 객관식 동형 문제

## 데이터 구조

- `Students`: 학생 프로필과 영구 포털 토큰·지문
- `Reports.StudentId`: 각 시험 결과를 학생 프로필에 연결
- 기존 시험별 `Token`·`Fingerprint`: 유지

## 기존 기록 연결

Apps Script에서 `migrateStudentPortals()`를 실행한다. 한 번에 최대 300개 기록을 처리하며 `done:false`이면 다시 실행한다. 학생 점수와 기존 개별 성적표 링크는 변경되지 않는다.

## 동명이인

교사용 화면에서 기존 학생을 명시적으로 선택할 수 있고, 다른 학생이면 `동명이인 신규 학생`을 선택한다. 반·번호 또는 외부 학생 ID가 있으면 자동 구분 정확도가 높아진다.
