# Young's Physics v3.6.1 적용 안내

## 변경 내용

- 물리1 15회 복습 테스트: 8문항, 100점
- 물리1 16회 복습 테스트: 6문항, 100점
- 두 회차 원문 PDF와 페이지 이미지 포함
- 14문항 모두 검수 정답, 상세 해설, 공식, 자주 하는 실수, 채점 루브릭 포함
- 14문항 모두 원문 재도전과 동형 문제를 4지/5지 객관식으로 제공
- 기존 v3.6.0 반별 학생 관리, 학생 영구 포털, 성적 수정/삭제 기능 유지

## 기존 운영본 적용

1. Google Sheets와 GitHub 저장소를 백업합니다.
2. `YoungsPhysics_물리1_15-16회추가_v3.6.1_GitHub패치.zip`을 압축 해제합니다.
3. 압축 내부 파일을 현재 GitHub 저장소 최상위에 경로 그대로 덮어씁니다.
4. `.github/workflows/pages.yml`, `site/assets/runtime-config.js`, `apps-script/Code.gs`는 이 패치에 포함되지 않으므로 기존 정상 설정을 유지합니다.
5. GitHub에 커밋하고 Pages 배포가 완료될 때까지 기다립니다.
6. 브라우저에서 `Ctrl+Shift+R`(Mac: `Cmd+Shift+R`)로 강력 새로고침합니다.
7. 교사 인증 후 `시험 설정 서버 동기화`를 한 번 실행합니다.
8. 물리1에서 15회와 16회가 `준비 완료`로 표시되는지 확인합니다.

이번 업데이트는 시험 데이터 추가이며 Google Sheets 스키마나 서버 API 변경이 없습니다. 따라서 다음 작업은 필요하지 않습니다.

## 검수상 교정 사항

### 15회 5번
이상적인 고정단/자유단 끝점 자체에는 투과파가 없습니다. 원문의 `투과파` 항목은 표준 경계면 투과 모형으로 해석해 투과파는 입사파와 동위상, 반사파는 고정단 역위상/자유단 동위상으로 적용했습니다.

### 15회 7번
원문 지시문이 `옳지 않은 것에 O, 잘못된 것에 X`로 서로 같은 의미를 두 번 써 모순됩니다. 시스템에서는 `옳은 것 O, 잘못된 것 X`로 교정했습니다.

### 16회 2번
원문에 배점이 표시되지 않았습니다. 다른 문항 배점 합이 90점이므로 시험 총점 100점에 맞춰 10점으로 적용했습니다.

### 16회 5번
볼록 거울 초점거리의 부호를 명시해 `거울 뒤 10 cm, 부호 포함 f=-10 cm`로 제공합니다.
