# Young’s Physics v3.6.5 · 두 학생 프로필 병합

## 기능

교사 인증 상태에서 `반별 학생 → 학생 데이터 병합`을 누릅니다. `흡수할 학생`을 먼저 고르고, `유지할 학생`을 고릅니다. 병합 전에 현재 저장된 시험 결과를 비교해 **같은 시험의 중복 성적**을 나열합니다. 중복 시험마다 최종 사용할 성적을 명시적으로 선택해야 병합할 수 있습니다. 학생 이름·학교가 다르면 경고 문구가 표시됩니다.

`유지할 학생`의 이름을 확인 입력하고 주의사항에 동의한 다음 병합을 실행하면, **유지할 학생의 프로필·영구 학부모 링크·기존 성적은 유지**됩니다. 중복되지 않은 시험 결과와 반 편성은 이 학생에게 합쳐집니다. 두 학생에게 같은 시험이 있으면 선택한 한 기록만 활성 성적에 남고, 나머지 기록은 복구용 스냅샷 시트에 보관됩니다.

안전상 **흡수할 학생의 영구 링크와 그 학생이 가지고 있던 개별 시험 링크는 무효화**됩니다. 이동된 시험 성적은 새 토큰·지문으로 다시 발급됩니다. 학생별 누적 통계 및 총괄 코멘트는 링크를 다시 열 때 최신 성적을 반영합니다. 반 편성 정보는 합집합으로 취급하며 동일 반 중복은 생성하지 않습니다.

## 설치 순서 (운영 v3.6.4에서 업그레이드)

1. 운영 Google Spreadsheet: `파일 → 사본 만들기`로 반드시 백업합니다. 기존 Apps Script `Code.gs`도 별도 보관합니다.
2. 운영 Spreadsheet의 `확장 프로그램 → Apps Script`에서 `Code.gs` 전체를 v3.6.5 파일로 교체해 저장합니다. `appsscript.json`은 변경하지 않습니다.
3. Apps Script에서 **`배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포`**를 실행합니다. 기존 `/exec` 배포 ID를 유지하세요.
4. GitHub 패치 ZIP의 내용물을 저장소 최상위 경로에 덮어쓰고 커밋합니다. ZIP 자체를 커밋하지 마세요.
5. GitHub Pages Actions 배포 성공 후 `Ctrl + Shift + R`로 강력 새로고침합니다.
6. 교사 인증 후 `반별 학생`에서 **서로 다른 두 테스트 학생**으로 미리보기·병합을 실행합니다. 기존 영구 링크 유지, 다른 학생 링크 비활성화, 중복 기록 선택, 반별 명단 등을 확인합니다.

이번 업데이트에서 `installYoungsPhysics()`, `resetTeacherPin()`, `migrateStudentPortals()`, `repairReportStorage()`를 실행할 필요가 없습니다. `StudentMerges`, `StudentMergeArchives`는 첫 병합 실행 시 자동 생성됩니다.

## 병합 동작 상세

| 항목 | 병합 후 |
|---|---|
| 유지할 학생 StudentId, 이름·학교·학년·반 | 유지 |
| 유지할 학생 영구 학부모 링크 | 그대로 유지 |
| 흡수할 학생 영구 학부모 링크 | 비활성화, 새 링크 요청 안내 |
| 흡수 학생의 기존 개별 시험 링크 | 보안상 무효화; 이동된 시험의 새 토큰 발급 |
| 중복 없는 과거 시험 | 유지할 학생에게 모두 이동 |
| 같은 시험 결과 중복 | 교사가 선택한 기록 1개만 운영에 유지, 나머지는 백업 |
| 반 편성 | 합집합으로 통합, 중복 배정 없음 |
| 기존 성취율·총괄 코멘트 | 최신 기록을 조회할 때 재계산 |
| 흡수 학생 프로필 | Students 시트에 비활성 기록으로 보존 |
| 복구용 스냅샷 | StudentMergeArchives 시트 |
| 실행 감사 기록 | StudentMerges 시트 |

### 예시

`홍길동(기존 A)`에 2·3·4회 성적이 있고 `홍길동(유지 B)`에 3·5회 성적이 있다면, 3회의 점수는 A/B 중 **하나를 직접 선택**합니다. 완료 후 유지 B 프로필에는 2·3·4·5회의 성적이 들어갑니다. 다른 학생의 시험 데이터가 자동으로 섞이지 않도록 토큰과 프로필을 재검증합니다.

## 문제 해결

- **`STUDENT_MERGE_PREVIEW_STALE`**: 미리보기 후 기록이 변경되었습니다. 다시 미리보기를 실행해야 합니다.
- **`STUDENT_MERGE_UNLINKED`**: StudentId가 없는 과거 성적이 남았습니다. 먼저 학생 통합 포털 마이그레이션 상태를 검사하세요. 백업 없이 임의 수정하지 마세요.
- **`STUDENT_MERGE_DUPLICATE_TOKEN`**: 서버에 동일한 성적 토큰이 중복돼 있습니다. 병합 전에 데이터 무결성을 점검하세요.
- **`STUDENT_MERGE_RESOLUTION_REQUIRED`**: 중복된 각 시험에 보존할 성적을 직접 고르세요.
- **`STUDENT_PROFILE_INACTIVE`**: 이미 흡수되어 비활성화된 학생입니다. 유지할 학생 프로필을 선택하세요.
- **`STUDENT_MERGE_RECOVERY_REQUIRED`**: Google Sheets 쓰기 오류 뒤 일부 복구가 끝나지 않았을 수 있습니다. **다시 병합하지 말고** `StudentMerges`의 병합 ID와 `StudentMergeArchives` 스냅샷으로 관리자 복구를 진행하세요.

### 중요 제한

Google Sheets는 여러 시트를 가로지르는 데이터베이스 트랜잭션을 기본 제공하지 않습니다. 이 구현은 스크립트 잠금, 사전 백업, 실패 시 원본 롤백을 지원하지만 **Apps Script 강제 종료·실행시간 초과 같은 중단**은 수동 복구가 필요할 수 있습니다. 실제 학생 기록에 적용하기 전에 반드시 Spreadsheet 사본을 만드세요. 그리고 두 학생이 실제로 동일인인지 교사가 확인해야 합니다.
