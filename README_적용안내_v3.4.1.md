# Young’s Physics v3.4.1 적용 안내

## 적용되는 변경

- 물리1·물리2 **총괄평가** 1~20번은 교사가 `0/1` 정오표가 아니라 학생이 실제로 선택한 객관식 번호 `1~5`를 입력합니다.
- 시스템이 현재 검수 정답표와 비교하여 문항별로 4점 또는 0점으로 자동 채점합니다.
- 21~25번은 기존처럼 학생의 실제 서술형 획득 점수를 입력합니다.
- 주간 복습 테스트의 `0`, `1`, 부분점수, `P1` 규칙은 바뀌지 않습니다.
- CSV의 이름 열은 `이름`, `성명`, `학생명`, `학생 이름`, `학생 성명`, `응시자명`, `수험자명`, `Name`, `StudentName` 등을 자동 인식합니다.
- UTF-8, UTF-8 BOM, CP949/EUC-KR, UTF-16LE/BE CSV와 쉼표·탭·세미콜론 구분자를 지원합니다.

## 기존 운영 시스템 업데이트

### 1. Google Spreadsheet 백업

운영 Spreadsheet에서 다음을 실행합니다.

```text
파일 → 사본 만들기
```

기존 `Reports`, `Questions`, 학생 토큰과 링크는 삭제하지 않습니다.

### 2. Apps Script Code.gs 교체

```text
Spreadsheet → 확장 프로그램 → Apps Script → Code.gs
```

1. 현재 코드를 별도 보관합니다.
2. 기존 내용을 모두 삭제합니다.
3. `YoungsPhysics_총괄선택번호_CSV수정_v3.4.1_Code.gs` 전체 내용을 붙여넣습니다.
4. 저장합니다.

`appsscript.json`의 OAuth 권한은 바뀌지 않았으므로 기존 파일을 그대로 사용해도 됩니다.

다음 함수는 다시 실행하지 않습니다.

```text
installYoungsPhysics()
resetTeacherPin()
repairReportStorage()
```

### 3. Apps Script 웹 앱 새 버전 배포

```text
배포 → 배포 관리 → 기존 웹 앱 편집 → 버전: 새 버전 → 배포
```

설정은 기존과 같습니다.

```text
실행 사용자: 나
액세스 권한: 모든 사용자
```

서버 API 식별 문자열은 기존 정상 통신을 유지하기 위해 `3.3.0-hosted-parent-bridge`를 그대로 사용합니다. 기존 `/exec` 주소가 유지되면 GitHub의 서버 주소 설정을 변경하지 않습니다.

### 4. GitHub 패치 적용

`YoungsPhysics_총괄선택번호_CSV수정_v3.4.1_GitHub패치.zip`을 압축 해제한 뒤 내부 파일을 저장소 최상위에 경로 그대로 덮어씁니다.

이 패치는 다음 운영 파일을 포함하지 않습니다.

```text
.github/workflows/pages.yml
site/assets/runtime-config.js
```

따라서 현재 정상 작동 중인 GitHub Pages workflow와 Apps Script `/exec` 주소는 유지됩니다.

커밋 메시지 예시:

```text
Use student choice numbers for comprehensive assessments and improve CSV import
```

### 5. GitHub Pages 재배포

새 커밋으로 생성된 Actions 실행이 완료될 때까지 기다립니다. 기존 실패 실행의 재실행보다 새 커밋에서 생성된 실행을 사용하는 것이 안전합니다.

배포 후 브라우저에서 강력 새로고침합니다.

```text
Windows: Ctrl + Shift + R
Mac: Command + Shift + R
```

### 6. 시험 설정 서버 동기화

교사용 홈페이지에서 다음을 한 번 실행합니다.

```text
교사 연결됨 → 시험 설정 서버 동기화
```

이 작업으로 Google Sheets의 `Questions`에도 총괄 객관식 입력 모드가 `objective-choice`로 반영됩니다. 서버 코드에는 구형 Questions 행을 자동 보정하는 호환 로직도 포함되어 있습니다.

## 수동 입력 방법

### 물리1·물리2 총괄평가

```text
1~20번: 학생이 고른 번호 1, 2, 3, 4, 5
21~25번: 실제 획득 점수
```

객관식 카드에는 ①~⑤ 버튼이 표시되며 키보드로 1~5를 입력해도 됩니다.

### 주간 복습 테스트

```text
0    오답·0점
1    정답·문항 만점
P1   정확히 1점 부분점수
기타 숫자  실제 부분점수
```

## CSV 형식

권장 헤더 예시:

```csv
과정,시험,학교,성명,학년,반번호,Q1,Q2,Q3,Q4,Q5,Q6,Q7,Q8,Q9,Q10,Q11,Q12,Q13,Q14,Q15,Q16,Q17,Q18,Q19,Q20,Q21,Q22,Q23,Q24,Q25
물리1,역학 총괄평가,,홍길동,2,1반 3번,5,2,3,5,1,3,2,3,1,3,4,4,4,5,3,2,3,2,2,2,4,3,2,1,0
```

### 이름 헤더 자동 인식

다음 중 하나를 사용할 수 있습니다.

```text
이름
성명
학생명
학생 이름
학생 성명
응시자명
수험자명
Name
StudentName
```

공백이 포함된 `성 명`, `이 름`, `학생 성명(필수)` 같은 표현도 정규화하여 인식합니다. 파일 앞쪽에 안내문이 있어도 처음 약 35행을 검사해 헤더를 찾습니다.

### 문항 헤더 자동 인식

다음 형식을 지원합니다.

```text
Q1, Q2, ...
1번, 2번, ...
문항1, 문항2, ...
문제1, 문제2, ...
객관식1, 답안1, ...
1, 2, 3, ...
```

### 이름 열 오류가 계속 뜰 때

1. 배포된 페이지가 v3.4.1인지 강력 새로고침합니다.
2. CSV 헤더에 위 이름 별칭 중 하나가 실제로 있는지 확인합니다.
3. 파일을 UTF-8 CSV 또는 CP949 CSV로 다시 저장해 첨부합니다.
4. CSV 템플릿 버튼으로 새 템플릿을 내려받아 데이터를 붙여넣습니다.

이름 열이 실제로 전혀 없는 파일은 학생 기록을 구분할 수 없으므로 저장을 차단합니다.

## 기존 데이터 호환

- 기존 총괄평가의 `0/1` 또는 `O/X` 기록은 `legacy-binary` 방식으로 유지됩니다.
- 새 총괄평가 기록은 `objective-choice-v1`로 저장됩니다.
- 동일 시험·학교·이름을 CSV나 Excel로 다시 저장하면 기존 행을 수정하고 학생 토큰과 학부모 링크를 유지합니다.
- 정답표를 홈페이지에서 수정했다면 이후 수동 입력·CSV·Excel 채점에 최신 정답이 적용됩니다.

## 최종 확인

```text
1. 물리1 → 역학 총괄평가 선택
2. 1번에 학생 선택번호 5 입력 → 4점 확인
3. 1번에 학생 선택번호 1 입력 → 0점 확인
4. Q1~Q25와 성명 헤더가 있는 CSV 첨부
5. 학생 이름과 선택번호가 미리보기에 나타나는지 확인
6. 테스트 학생 1명 저장
7. Reports 행과 학생 링크 확인
8. 다른 컴퓨터에서 같은 기록 자동 조회 확인
```
