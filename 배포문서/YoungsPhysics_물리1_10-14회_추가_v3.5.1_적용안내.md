## 기존 운영 저장소에 적용

1. 운영 GitHub 저장소를 백업한다.
2. 제공된 GitHub 패치 ZIP을 압축 해제한다.
3. ZIP 내부 파일을 저장소 최상위에 경로 그대로 덮어쓴다.
4. 커밋하고 기존 GitHub Pages workflow가 완료될 때까지 기다린다.
5. 사이트에서 `Ctrl+Shift+R` 또는 `Command+Shift+R`로 강력 새로고침한다.
6. 교사 인증 후 **시험 설정 서버 동기화**를 한 번 실행한다.
7. 과정 `물리1`에서 10~14회가 `준비 완료`로 보이는지 확인한다.
8. 테스트 학생 1명을 저장한 뒤 학생 통합 링크에 새 회차가 누적되는지 확인한다.

## Apps Script 작업

이번 변경에는 서버 코드나 Google Sheets 스키마 변경이 없다. 따라서 아래 작업은 하지 않는다.

- `Code.gs` 교체
- `appsscript.json` 변경
- `installYoungsPhysics()` 실행
- Apps Script 새 버전 배포
- 교사 PIN 재설정
- 기존 학생 포털 마이그레이션 재실행

단, 정적 카탈로그를 Google Sheets의 `Exams`와 `Questions`에 반영하려면 홈페이지의 **시험 설정 서버 동기화**가 필요하다.

## 확인 필요 문항

13회 7번은 솔레노이드 권선의 앞·뒤 연결 방향이 그림에 없어 A·B 중 N극을 하나로 확정할 수 없다. `needs-review` 상태로 등록되어 학생에게 정답과 해설이 자동 공개되지 않는다. 향후 권선 방향이 보완된 그림이 제공되면 홈페이지의 정답 관리에서 활성화한다.
