# v3.7.11 원본 PDF 최종 등록판 — v3.7.10에서 직접 적용

이 패키지는 이전에 제공한 재구성 자료 포함 v3.7.11 및 원본 교체용 Builder를 대체합니다. 이전 v3.7.11을 먼저 적용하지 마세요. 실제 GitHub/Apps Script/Google Sheets/Worker에는 이 작업에서 접속하거나 배포하지 않았습니다.

## 변경 범위

- `physics2-advanced-r05` 하나를 신규 등록: 7문항, 100점, 배점 15·15·15·15·15·15·10.
- 이번 첨부 `물리2심화 Quiz 5회(2).pdf`, `물리2심화 Quiz 5회 해답(2).pdf`를 바이트 그대로 포함.
- 원문 문제·그림은 문제 PDF 4쪽을 200 dpi로 렌더링하고 원래 문항 영역을 그대로 자릅니다. 재작도·문제 문장 재작성·해답 이미지로 문제 대체는 하지 않습니다.
- 4번은 거친 구간과 원형 궤도, 6번은 공/상자 충돌, 7번은 움직이는 빗면인 버전입니다. 앞서 잘못 함께 올라온 자동차/인공위성/쌍성 해답은 사용하지 않습니다.
- 원문 답과 검수 보충 설명을 구분합니다. 새 동형 객관식 7문항은 원문과 별도 작성된 연습문제로 표시합니다.
- 기존 45개 시험은 심화 총괄의 연결 목록에 r05를 추가하는 것 외에 동일합니다. 기존 문제 JSON/PDF/PNG 및 모든 핵심 응용 코드와 서버 코드는 그대로입니다.

## 적용 전에

1. 현재 GitHub 저장소 전체 ZIP/커밋과 운영 Sheets를 백업합니다. 아직 배포하지 않은 변경이 있으면 먼저 보존합니다.
2. 현재 GitHub 저장소의 최신 ZIP 또는 로컬 저장소를 읽기 전용 검사합니다.

   `python CHECK_PATCH_v3.7.11_original.py 현재소스폴더`

   또는 `python CHECK_PATCH_v3.7.11_original.py 현재저장소.zip`

3. `PASS BASE`가 나와야 v3.7.10 기준 패치를 적용합니다. `STOP`이면 덮어쓰지 말고 차이를 비교하세요. `PASS TARGET`이면 같은 최종본이 이미 적용된 상태입니다. 버전 번호만 같은 다른 v3.7.11은 호환 대상으로 취급하지 않습니다.
4. 운영 `Exams`, `Questions`, `QuestionOverrides`, `Reports`에서 `physics2-advanced-r05`의 선등록·개별 수정·성적이 있는지 확인합니다. v3.7.11 미적용이라는 사용자 설명을 기준으로 신규 시험을 추가했지만, 실제 운영 DB의 내용을 읽지는 않았습니다.
5. 기존 교사 앱은 카탈로그 버전 변경을 감지하면 `autoSyncCatalog(false)`로 자동 동기화할 수 있습니다. **정적 배포 또는 로그인된 교사 화면 재접속 전에** Sheets 사본을 만들어야 합니다. 수동 동기화 버튼을 누르기 전까지만 백업하면 되는 것이 아닙니다.

## 적용 순서

백업과 사전검사가 끝난 뒤 이번 증분 ZIP의 파일을 저장소 루트 기준 경로에 맞게 반영합니다. ZIP 파일 자체를 사이트 파일로 올리거나 최상위 폴더를 한 겹 더 만들지 마세요. `site/assets/data/catalog.json`, `catalog.js`, 독립 문항 JSON, 2개 원본 PDF, 4개 원문 페이지 PNG가 함께 들어가야 합니다.

로컬 `npm test` 통과 후 평소 GitHub Pages 배포 절차를 사용합니다. `.github/workflows/pages.yml`, `runtime-config.js`, `share-config.js`는 이번 패치 대상이 아닙니다. Apps Script와 Cloudflare Worker는 수정·재배포할 필요가 없습니다. 실제 실행 주소와 비밀값도 변경하지 않습니다.

배포 후 자동 동기화 결과를 확인하고, 필요한 경우에만 기존 교사 화면의 시험 설정 동기화를 수행합니다. 서버 `syncCatalog`는 설정 시트를 교체할 수 있고 `QuestionOverrides`는 별도로 남을 수 있으므로 먼저 충돌을 확인하세요. `Students`/`Reports`를 수동 초기화하지 마세요.

화면 확인: 물리2심화 5회차 입력 7칸/100점, 6번15점(10+5), 원문 그림 7개, 문제지/해답 링크, 원문·동형 재도전, 기존 4회 구형/개정판, 물리1 16회 신구분리, 총괄 성적표 버튼.

## 배점·해설 주의

6번 문제지는 15점(10+5), 해답지는 20점(10+10)입니다. 원본 PDF를 고치지 않고 입력 배점만 문제지 기준으로 맞췄습니다. 7번은 원문 총10점만 사용하며 임의의 4+6점 세부 배점은 만들지 않았습니다. '초파를 그리면 2점'은 기본100점에 자동 합산하지 않습니다.

1번의 작은 공·간격·충돌높이 무시, 2번 줄이 팽팽한 진자운동 범위, 3번 서로 다른 정상 원운동 비교, 6번 상자 초기 정지, 7번 에너지 손실 없는 이상적 진입은 원문 해답을 해석하기 위한 검수 보충으로 구분했습니다. 학생 점수의 자동 재채점이나 기존 성적 변경은 하지 않습니다.

## 되돌리기

배포 전이라면 적용 전 커밋/저장소 ZIP으로 파일을 되돌립니다. 새 5회 성적을 저장하기 전이라면 이전 v3.7.10 커밋으로 정적 파일을 되돌릴 수 있습니다. 시험 설정이 이미 동기화됐으면 차이를 확인하여 필요한 설정 행만 복원합니다.

**새 5회 성적이 하나라도 생긴 뒤에는** 이전 v3.7.10 전체를 덮어쓰거나 r05 정의·문항·원본 자료를 삭제하지 마세요. 기존 성적을 열 수 있도록 r05 정의와 자료를 유지한 상태에서 문제가 있는 변경만 되돌려야 합니다. 백업 이후 새 성적이 있으므로 Sheets를 옛 사본으로 통째로 덮어쓰지 마세요. 학생 ID/토큰/지문 재발급, `installYoungsPhysics()`, 저장소 복구·마이그레이션·초기화 함수를 실행하지 마세요.

## 검증 범위

로컬 자동 테스트와 가상 학생 오프라인 Chromium 검사는 실제 운영 서버 검증을 대신하지 않습니다. 실제 운영 GitHub 커밋, Apps Script 배포 버전, 운영 Sheets 및 Worker 상태는 미확인입니다. 운영 배포는 사용자 승인 후 별도 절차입니다.
