# Young’s Physics v3.7.8 – 학부모 통합 페이지 총괄평가 성적표 바로 보기

## 기능
- 학부모 통합 페이지의 기본 ‘누적 요약’ 화면 상단에 **총괄평가 성적표 바로 보기** 전용 영역을 표시합니다. 총괄평가가 없는 학생에게는 이 영역이 나타나지 않습니다.
- 기본 요약의 ‘최근 시험 결과’ 혼합 목록을 ‘최근 주간 복습 결과’로 바꾸어, 총괄평가와 주간 테스트를 분리합니다.
- 총괄평가 카드에는 **성적표 바로 보기**(강조)와 기존 **시험 결과·분석 보기**(보조)를 함께 제공하고, ‘총괄평가’ 탭에서도 두 버튼을 유지합니다. 주간 테스트 카드는 기존 시험 분석 버튼만 제공합니다.
- 성적표 버튼은 기존 `report.html`을 새 탭으로 열며, 그 페이지의 PDF 인쇄·Word 출력 기능을 그대로 이용합니다.
- 모바일에서도 총괄평가 성적표 버튼을 바로 이용할 수 있고, 팝업이 차단되면 검증 후 현재 탭으로 이동합니다.

## 학생 데이터 및 권한 보호
- 통합 목록에 개별 성적표 fingerprint를 추가하지 않습니다. 사용자가 클릭하면 **기존 Apps Script의 `getStudentExamDetail`**을 사용해 `portalToken`, `portalFingerprint`, `reportToken`에 대한 학생 소유권을 확인하고, 서버가 반환한 해당 기록의 token/fingerprint로만 개별 성적표 URL을 만듭니다.
- 시험 ID, 학생 ID, 교사용 입력, 총괄·주간 시험의 문제/정답, 오답 학습, 기존 학생 영구 링크는 변경하지 않습니다.
- `Code.gs`, `appsscript.json`, Cloudflare Worker, `pages.yml`, `runtime-config.js`, `share-config.js`, `api.js`, `core.js`, `report.js` 변경이 없습니다.

## 적용 안내 – 반드시 실제 운영 소스와 대조
1. 현재 운영 GitHub 소스/커밋을 백업하고, 아래 매니페스트의 기준 SHA-256과 각 수정 대상 파일을 대조합니다. **미일치 시 적용 중단**하십시오.
2. v3.7.7 정본(2026-11-02 누락 v3.7.5 복구 완료본 포함)을 기준으로 이 ZIP의 상대경로에 따라 파일을 덮어씁니다. 새로운 `PATCH_MANIFEST_v3.7.8.json`은 검증용입니다.
3. GitHub Pages 배포를 명시적으로 진행할 때만 변경을 반영하고, 통합 포털에서 `누적 요약 → 총괄평가 성적표 바로 보기` 및 `총괄평가` 탭을 확인합니다.
4. `report.html` 성적표는 기존 링크 체계로 연결됩니다. 버튼 클릭 시 본인 학생의 총괄평가만 조회되는지, 주간 카드에는 직접 성적표 버튼이 없는지 확인합니다.
5. 이번 변경은 정적 웹 UI만 수정합니다. Apps Script 재배포나 Google Sheets 시험 설정 동기화는 **필요하지 않습니다**.

**중요:** 운영 사이트가 v3.7.4에서 v3.7.5를 건너뛰고 v3.7.6·v3.7.7만 적용한 상태라면, 이전에 별도 제공한 **v3.7.7 누락 v3.7.5 안전복구패치**가 먼저 적용되었는지 확인해야 합니다. 이 v3.7.8 패치는 그 누락을 보완하지 않습니다.
