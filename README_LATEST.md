# 최신 수정본: v3.7.17

물리2 3회차 복습테스트를 실제 원본의 1~8번, 100점으로 복구한 수정본입니다. 별도 개념정리 퀴즈가 16문항으로 잘못 연결되었던 문제를 수정했습니다.

이번 수정에는 기존 성적의 문항 구성을 구분하는 서버 코드가 포함됩니다. `README_3717_apply.md`의 순서대로 Apps Script의 기존 웹 앱을 새 버전으로 갱신한 뒤 GitHub 패치를 반영합니다. 학생 식별값과 영구 링크를 새로 만들지 않습니다.

현재 v3.7.15 또는 v3.7.16이면 `YP3717_R03_fix.zip`, v3.7.13이면 `YP3717_cumulative_from3713.zip`을 사용합니다. 전체 소스는 보관·비교용입니다. 운영 사이트에 자동 배포하거나 실제 학생 데이터를 변경하는 프로그램은 포함하지 않습니다.

3.7.16 이전 README와 검증 로그는 당시 작업의 기록입니다. 현재 적용 절차와 검증 결과는 `README_3717_apply.md`, `VALIDATION_3717.md`를 따릅니다.
