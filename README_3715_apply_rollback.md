- 문항의 글·그림·수식·선택지를 문제지 PDF에서 200dpi 그대로 잘라 10문항 `image.page`와 `image.crop`으로 연결합니다. 재작성·재도안하지 않았습니다.
- `physics2-basic-r02`는 서술형 10문항·100점 `[10,10,10,10,10,10,10,10,10,10]`이며 기존 시험 ID를 유지합니다.
- 교사 성적입력 `1`=문항만점, `0`=0점, `P1`=1점, 유효한 실수 부분점수 및 공란=미채점. 학생용 원문 기반 4지 재도전 10개·별도 동형 10개·오답 분석·교정 해설까지 연결합니다.
- **9번 해답지의 벡터/기준 혼동**: 실제 답 `(1) 강둑 기준 2m/s, (2) 강물 기준 2√2m/s`로 교정. 원본 해답 PDF는 원형 그대로 보존하고 `r02-reviewed-solution.pdf` 및 `correctionNote`에 차이를 구분했습니다.
- 2회차가 물리2 역학 총괄의 누적 분석 목록에 이미 들어 있어 해당 `historyExamIds`는 그대로 유지합니다.
- ‘초파를 그리면 2점’ 문구는 기본 100점 점수에 자동 가산하지 않습니다.

- 현재 운영 저장소가 **v3.7.13**이라면 `YP_3715_cumulative_patch_from_3713.zip`을 사용하고 `CHECK_3715_FROM_3713.py`를 먼저 실행하세요. 누적 패치에 심화6회차의 **최종 원본** 등록이 포함됩니다.
- 두 ZIP을 함께 적용하지 마세요. 기존 초기 v3.7.14(최종 교체판이 아닌 이전 소스) 위에 덮어쓰지 마세요. 사전검사가 `STOP`을 반환하면 즉시 중단합니다.

1. 배포 전 실제 운영 GitHub의 전체 소스 ZIP과 Google Sheets의 `Students`, `Reports`, `Courses`, `Exams`, `Questions`, `QuestionOverrides` 시트를 백업합니다. **교사 페이지에 다시 로그인하거나 배포하기 전**에 먼저 백업하세요. 카탈로그 변경 시 자동 서버 동기화가 실행될 수 있습니다.
2. 받은 패치 ZIP을 PC에 풀고, 현재 GitHub 전체 저장소 ZIP 또는 소스폴더에 대해 `python CHECK_3715_FROM_3714.py /path/to/current.zip` 또는 `CHECK_3715_FROM_3713.py`를 실행합니다. `PASS_BASE`여야 합니다. `ALREADY_COMPLETE`이면 재적용할 필요 없습니다. `STOP`이면 덮어쓰지 마세요.
3. ZIP 파일 자체를 GitHub에 그대로 올리는 것이 아닙니다. 내부 파일을 기존 저장소의 **동일한 상대 경로**에 추가·덮어씁니다. 지정하지 않은 기존 파일과 원래 운영 서버 설정을 삭제하지 마세요.
