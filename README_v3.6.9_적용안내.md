## 중요한 내용

## 운영본 설치

1. Google Spreadsheet `파일 → 사본 만들기`로 먼저 백업하고 GitHub 저장소도 백업하세요.
2. `youngs-physics-conditional-answers-v3.6.9-patch.zip`을 압축 해제하세요. ZIP 자체가 아니라 내부 파일 및 폴더를 GitHub 저장소 **최상위**에 경로대로 덮어쓰세요.
3. `Commit changes`로 커밋하세요(예: `Release condition-qualified solutions for 4 review questions`). GitHub Actions → Pages 배포가 정상 완료됐는지 확인하세요.
4. 교사용 웹사이트를 `Ctrl+Shift+R`로 강력 새로고침한 뒤 교사 인증 → **시험 설정 서버 동기화**를 한 번 실행하세요. 이렇게 해야 운영 Google Sheets의 Questions 시트가 최신 보충 조건·해설로 업데이트됩니다.
5. 물리1 3·5·13회, 물리2 11회를 골라 해당 번호에 `교정 적용`과 `추가 풀이 조건`이 표시되는지 확인하세요.
6. 오답이 있는 테스트 학생 통합 학습 페이지에서 `원문 재도전 → 객관식 답 제출 → 정답/해설 → 동형 문제`가 표시되는지 확인하세요.
7. 물리2 11회차의 `원문 해설지 PDF` 버튼은 새 이름 `r11-conditional-solution-v3.6.9.pdf`를 가리키며, 8번 조건부 해설이 포함되어 있습니다.

## 수정할 필요 없는 파일

`apps-script/Code.gs`, `apps-script/appsscript.json`, `.github/workflows/pages.yml`, `site/assets/runtime-config.js`, `site/assets/share-config.js`는 패치에 포함되지 않습니다. Apps Script를 재배포하거나 교사 PIN, Cloudflare 서버를 수정할 필요가 없습니다. 학생 영구 링크·반 편성·학생 병합 데이터도 그대로 보존됩니다.

## 기존 서버 `QuestionOverrides` 주의

교사가 이전에 해당 문항의 정답이나 객관식 보기를 직접 수정했다면 서버 `QuestionOverrides` 내용이 카탈로그 기본값보다 우선할 수 있습니다. `정답 관리`에서 **해당 문항만** `원본으로 되돌리기`를 수행하거나 선생님의 커스텀 답을 확인하세요. 다른 문항의 커스텀 정답을 일괄 초기화하지 마세요.

## 공식 채점 관련

원문에 없던 전제는 학습용 모델에 명확하게 적혀 있습니다. 이를 실제 시험의 원문 공식 정답과 동일시하지 않습니다. 사이트 자동 학습 공개 변경은 기존 학생의 `Reports` 획득 점수, 총점, 통계, 학부모 링크를 자동 변경하지 않습니다.
