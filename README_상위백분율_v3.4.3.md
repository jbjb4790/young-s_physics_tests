# Young’s Physics v3.4.3 — 총괄평가 상위 백분율 표시

## 표시 규칙

- 대상: `assessmentType = comprehensive`인 총괄평가
- 비교 집단: 같은 과정·같은 시험(`courseId + examId`) 응시자
- 순위: 자신보다 점수가 높은 학생 수 + 1의 경쟁 순위
- 동점: 같은 순위와 같은 상위 비율 적용
- 표시 조건: 계산된 상위 비율이 50% 이하일 때만 첫 화면에 `상위 N%` 표시
- 표시 정밀도: 공동 순위 비율을 소수 첫째 자리까지 표시
- 화면 노출: 석차 숫자는 표시하지 않고 `상위 N%`, 응시 인원, 동점자 수만 표시
- 주간 복습 테스트: 표시하지 않음

## 출력

- 학생·학부모용 웹 성적표 첫 화면
- 인쇄/PDF 첫 화면
- 실제 `.docx` Word 성적표 첫 요약 영역
