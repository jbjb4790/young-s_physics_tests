심화 총괄 1~25번 전체를 학생 선택번호로 입력

교사 인증 후 상단 정답 관리 메뉴에서 선택한 시험의 공식 정답·모범답안, 원문 재도전 보기와 동형 문제 보기를 편집할 수 있습니다. 저장값은 Google Sheets의 QuestionOverrides 시트에 보존되어 다른 컴퓨터와 학생 성적표에도 적용됩니다.

선택형 재도전: 준비 완료된 원문·동형 108문항은 모두 보기 선택 방식이며, 서술형·단답형 65문항과 답안번호가 별도 등록되지 않은 복합 선택형 3문항도 정확한 문자열 입력이 필요하지 않습니다.
SCORING POLICY

총괄평가 입력 규칙

일반 물리1·물리2: 1~20번 선택번호 1~5, 21~25번 실제 획득 점수
물리1심화·물리2심화: 1~25번 모두 선택번호 1~5

심화 총괄 문항의 공식 정답 번호가 등록되지 않은 경우 저장을 차단하고 정답 관리 화면에서 먼저 정답 번호를 입력하도록 안내합니다.

UPDATE

기존 운영 시스템에 3.4.2 적용

  1. 운영 Google Spreadsheet를 파일 → 사본 만들기로 백업합니다.
  2. Apps Script의 기존 Code.gs를 3.4.2 파일로 전체 교체하고 저장합니다.
  3. installYoungsPhysics(), resetTeacherPin(), repairReportStorage()는 다시 실행하지 않습니다.
  4. 배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전으로 재배포합니다.
  5. GitHub에는 v3.4.2 패치 파일을 경로 그대로 덮어씁니다.
  6. 기존에 정상화한 .github/workflows/pages.yml과 site/assets/runtime-config.js는 덮어쓰지 않습니다.
  7. Pages를 다시 배포하고 브라우저를 강력 새로고침합니다.
ANSWER MANAGER

시험 정답·보기 수정 방법

  1. 과정과 시험을 선택합니다.
  2. 상단 메뉴의 정답 관리로 이동합니다.
  3. 문항 카드를 펼쳐 객관식 정답 번호 또는 서술형 모범답안을 수정합니다.
  4. 원문 문제 다시 풀기 보기와 동형 문제 보기의 문구를 수정하고 정답 보기를 선택합니다.
  5. 필요하면 수정 메모를 입력합니다.
  6. 정답·보기 저장을 누릅니다.

보기는 2~6개이며 빈 보기나 중복 보기는 저장이 차단됩니다. 정답 보기로 선택한 문구가 학생에게 공개되는 정답 문구와 함께 갱신됩니다.

DATA SAFETY

원본과 수정본의 분리

Questions 시트는 배포 카탈로그의 검수 원본이고, 홈페이지 수정값은 QuestionOverrides에 별도로 저장됩니다. 따라서 시험 설정 서버 동기화를 다시 실행해도 운영 중 수정한 정답과 보기가 사라지지 않습니다.

시험 원본으로 되돌리기를 누르면 해당 시험의 override만 삭제하고 배포된 검수 원본을 다시 사용합니다.

REGRADING

정답을 바꾼 뒤 기존 학생 점수

정답 수정은 앞으로의 Excel 재채점과 새로 여는 학생 리포트의 정답·해설에 적용됩니다. 이미 Reports에 저장된 학생 점수는 자동으로 바꾸지 않습니다.

기존 학생 재채점: 같은 Excel을 다시 일괄 저장하거나 학생 기록을 수정 저장하세요. 동일 시험·학교·이름은 기존 토큰과 학부모 링크를 유지한 채 갱신됩니다.
RETRY FLOW

학생 오답 재도전

  1. 원문 문제 이미지와 선택 보기를 확인합니다.
  2. 답을 고르고 답 제출 후 해설 보기를 누릅니다.
  3. 정오 판정 뒤 검수된 정답·해설·공식·부분점수 기준이 공개됩니다.
  4. 동형 문제가 활성화되면 보기를 선택해 제출합니다.
  5. 제출 뒤 동형 문제 정답과 풀이가 공개됩니다.

학생이 수식의 공백, 단위 기호, 분수 표기나 문장 띄어쓰기를 정확히 입력하지 않아도 됩니다.

EXCEL

Excel 자동 입력과 수정 정답

일반 물리1·물리2 총괄은 1~20번 학생 선택번호와 21~25번 실제 점수를 사용합니다. 물리1심화·물리2심화 총괄은 1~25번 모두 학생 선택번호 1~5를 저장하고 최신 정답표와 비교해 채점합니다. CSV는 이름·성명·학생명·학생 이름·학생 성명·Name 헤더, 쉼표·탭·세미콜론 구분자와 UTF-8·CP949를 자동 감지합니다.

  1. 시험을 선택합니다.
  2. Excel·CSV 일괄 입력에 파일을 첨부합니다.
  3. 정답·총점·신규/수정 미리보기를 확인합니다.
  4. 검증된 학생 기록 일괄 저장을 누릅니다.
AUTOMATIC CONNECTION

다른 컴퓨터 자동 연결

GitHub Pages는 기존 runtime-config.js에 설정된 Apps Script /exec 주소를 사용합니다. 새 컴퓨터에서는 같은 Pages 주소를 열고 교사 PIN을 최초 한 번 입력하거나, 기존 컴퓨터에서 만든 10분짜리 1회용 연결 링크를 사용합니다.

접속·새로고침·탭 복귀·네트워크 재연결 시 학생 기록과 정답 수정본을 다시 불러옵니다.

SECURITY

보안 원칙

  • GitHub에는 실제 학생 이름·학교·점수·토큰을 넣지 않습니다.
  • 교사 PIN, 세션 토큰, WRITE_KEY와 서명 비밀값을 공개 파일에 넣지 않습니다.
  • 학생 데이터의 원본은 Google Sheets입니다.
  • 학생 링크는 서버 토큰·지문·학생 식별 다이제스트를 검증합니다.
  • 정답 수정 API는 교사 세션 인증을 통과한 요청만 허용합니다.
CHECK

적용 후 확인

  1. /exec?action=ping에서 기존 정상 API 버전을 확인합니다.
  2. Pages에서 교사 PIN 인증이 유지되는지 확인합니다.
  3. 정답 관리에서 테스트 문항의 보기 한 곳을 수정해 저장합니다.
  4. 다른 컴퓨터에서 같은 문항에 서버 수정본 표시가 나오는지 확인합니다.
  5. 테스트 학생 링크에서 원문·동형 답안이 모두 드롭다운 보기로 표시되는지 확인합니다.
  6. 확인 후 시험 원본으로 되돌리기로 테스트 override를 삭제합니다.
