VERSION 3.2

어느 컴퓨터에서나 자동 연결하고 Excel 한 파일로 일괄 입력

GitHub Actions가 저장소 변수 YP_API_URL의 Apps Script /exec 주소를 Pages 배포본에 자동 삽입합니다. 새 컴퓨터에서는 교사 PIN을 한 번 입력하거나 1회용 연결 링크를 열면 됩니다.

학교가 비어 있으면 저장·목록·학생 리포트·Word에서 미기입으로 표시됩니다. 구버전의 미입력 학교 기록도 같은 학생으로 인식합니다.

Excel 원본은 브라우저에서만 읽습니다. 실제 학생 Excel 파일과 인증 비밀값은 공개 GitHub 파일에 저장하지 않습니다.
UPDATE FROM 3.1

1. 기존 운영본 업데이트

  1. Google Spreadsheet를 사본으로 백업합니다.
  2. Apps Script의 Code.gs와 appsscript.json을 3.2 파일로 교체합니다.
  3. installYoungsPhysics()를 실행합니다. 기존 PIN은 유지되고 학교 표기가 미기입으로 정리됩니다.
  4. 웹 앱을 새 버전으로 다시 배포합니다.
  5. GitHub에 3.2 패치 또는 전체 파일을 덮어쓰고 Pages를 재배포합니다.
PAGES ERROR

2. GitHub Pages 404 해결

Get Pages site failed: Not Found는 저장소에서 Pages가 아직 활성화되지 않았을 때 발생합니다.

  1. 저장소 Settings를 엽니다.
  2. Pages를 선택합니다.
  3. Build and deployment → Source → GitHub Actions를 선택합니다.
  4. Actions에서 실패한 workflow를 다시 실행합니다.
APPS SCRIPT

3. Code.gs 설치와 교사 PIN

  1. Spreadsheet에서 확장 프로그램 → Apps Script를 엽니다.
  2. 패키지의 Code.gs와 appsscript.json을 적용합니다.
  3. installYoungsPhysics()를 실행합니다.
  4. 표시되는 10자리 교사 PIN을 보관합니다.
  5. 웹 앱을 실행 사용자: 나 / 액세스: 모든 사용자로 배포합니다.
  6. /exec 주소를 복사합니다.
GITHUB VARIABLE

4. 서버 주소 자동 주입

  1. Settings → Secrets and variables → Actions → Variables
  2. 변수 이름을 YP_API_URL로 지정합니다.
  3. 값에 Apps Script /exec 주소를 넣습니다.
  4. main 브랜치에 파일을 올려 Pages를 다시 배포합니다.
PIN, 세션 토큰, WRITE_KEY는 GitHub 변수나 코드에 넣지 않습니다.
TEACHER DEVICE

5. 첫 컴퓨터와 새 컴퓨터

첫 컴퓨터: 우측 상단 교사 인증에서 PIN을 최초 1회 입력합니다.

새 컴퓨터: 같은 PIN을 한 번 입력하거나 기존 컴퓨터의 교사 연결됨 → 새 컴퓨터 연결 링크 복사를 사용합니다.

자동 갱신: 접속·새로고침·탭 복귀·창 포커스 복귀·네트워크 재연결 시 Google Sheets 기록을 다시 불러옵니다.
SCHOOL LABEL

6. 학교가 없는 학생

학교 칸을 비우거나 Excel에 학교 열이 없으면 미기입으로 저장됩니다. 첨부 역학 파일의 학원 열은 학교로 사용하지 않습니다.

기존 기록이 빈칸 또는 미입력이어도 3.2에서는 미기입과 같은 학생으로 연결합니다.

EXCEL IMPORT

7. 물리1 역학 총괄평가 Excel 자동 입력

  1. 과정 물리1, 시험 역학 총괄평가를 선택합니다.
  2. Excel·CSV 일괄 입력 영역에 .xlsx 파일을 첨부하거나 끌어놓습니다.
  3. 시스템이 1회 시트, 학생 행, 1~25번 문항, 원본 총점을 자동 탐색합니다.
  4. 객관식 선택 번호 1~20번은 검수 정답표와 비교해 0/1로 바꿉니다.
  5. 서술형 21~25번은 Excel의 실제 점수를 그대로 사용합니다.
  6. 학생 수·학교 미기입·재계산 점수·원본 총점·신규/수정을 미리 확인합니다.
  7. 검증된 학생 기록 일괄 저장을 누릅니다.
첨부 검증 결과: 학생 179명, 학교 미기입 179명, 원본 총점과 재계산 점수 불일치 0건.
UPSERT

8. 같은 파일을 다시 올릴 때

동일 시험·학교·이름의 기존 기록을 찾아 점수만 수정합니다. 학생 토큰, 지문과 학부모 결과 링크는 유지됩니다.

Excel 원본 파일 자체는 서버에 업로드하지 않고, 저장 버튼을 누를 때 정규화된 학생 기록만 Apps Script로 전송합니다.

ONE CLICK

9. 수동 입력과 링크 복사

  1. 학생 이름과 문항별 점수를 입력합니다.
  2. 학교는 비워도 됩니다.
  3. 저장·성적 분석·링크 복사를 누릅니다.
  4. Google Sheets 저장, 통계 재계산, 복습·총괄 연결, 학생 링크 복사가 한 번에 완료됩니다.
REPORT TOKEN

10. 성적표 토큰 오류 복구

학생 입력은 저장되지만 성적표 토큰을 찾을 수 없습니다가 나오면 Apps Script에서 diagnoseReportStorage()와 repairReportStorage()를 실행합니다.

그다음 Apps Script를 새 버전으로 배포하고 Pages를 다시 배포한 뒤, 교사용 화면의 서버 기록 새로고침 → 링크 복사로 새 링크를 전달합니다.

v3.2.4부터 새 링크에는 생성 당시 Apps Script /exec 주소와 서버 식별자가 들어가므로 다른 배포·Spreadsheet를 잘못 조회하지 않습니다.

  • 현재 컴퓨터만 해제: 사이트의 이 컴퓨터 연결 해제
