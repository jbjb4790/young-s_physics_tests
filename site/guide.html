AUTOMATIC CONNECTION

다른 컴퓨터 자동 연결

GitHub Pages는 기존 runtime-config.js에 설정된 Apps Script /exec 주소를 사용합니다. 새 컴퓨터에서는 같은 Pages 주소를 열고 교사 PIN을 최초 한 번 입력하거나, 기존 컴퓨터에서 만든 10분짜리 1회용 연결 링크를 사용합니다.

접속·새로고침·탭 복귀·네트워크 재연결 시 학생 기록과 정답 수정본을 다시 불러옵니다.

SECURITY

보안 원칙

  • GitHub에는 실제 학생 이름·학교·점수·토큰을 넣지 않습니다.
  • 교사 PIN, 세션 토큰, WRITE_KEY와 서명 비밀값을 공개 파일에 넣지 않습니다.
  • 학생 데이터의 원본은 Google Sheets입니다.
  • 학생 링크는 서버 토큰·지문·학생 식별 다이제스트를 검증합니다.
  • 정답 수정 API는 교사 세션 인증을 통과한 요청만 허용합니다.
CHECK

적용 후 확인

  1. /exec?action=ping에서 기존 정상 API 버전을 확인합니다.
  2. Pages에서 교사 PIN 인증이 유지되는지 확인합니다.
  3. 정답 관리에서 테스트 문항의 보기 한 곳을 수정해 저장합니다.
  4. 다른 컴퓨터에서 같은 문항에 서버 수정본 표시가 나오는지 확인합니다.
  5. 테스트 학생 링크에서 원문·동형 답안이 모두 ①~⑤ 객관식 카드로 표시되고 자유 입력칸이 없는지 확인합니다.
  6. 확인 후 시험 원본으로 되돌리기로 테스트 override를 삭제합니다.
