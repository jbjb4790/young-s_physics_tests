0. 기존 통합판에 로고·테마만 적용

총괄평가 통합판 2.0이 이미 정상 운영 중이면 리브랜딩 패치의 site/ 파일만 덮어쓴 뒤 GitHub Pages를 다시 배포합니다.

이번 디자인 패치만 적용할 때는 Code.gs 교체, Apps Script 재배포, Google Sheets 마이그레이션, 시험 설정 서버 동기화가 필요하지 않습니다. 기존 학생 토큰과 저장 데이터도 그대로 유지됩니다.
BEFORE UPDATE

1. 기존 운영 자료 백업

기존 주간 복습 시스템을 운영 중이면 Google Spreadsheet 사본과 현재 Code.gs를 먼저 백업합니다. 이번 버전은 기존 헤더 이름으로 데이터를 새 열 순서에 재배치하지만 실데이터 변경 전 백업은 필수입니다.

GOOGLE SHEETS

2. Code.gs 교체와 스키마 마이그레이션

  1. Apps Script의 기존 Code.gs를 패키지 파일로 교체합니다.
  2. Script Properties의 SPREADSHEET_ID, WRITE_KEY, FINGERPRINT_SECRET을 확인합니다.
  3. connectThisSpreadsheet()를 실행합니다.
  4. Exams, Questions, Reports의 새 열이 생성됐는지 확인합니다.
새 코드는 열 번호 위에 헤더를 덮어쓰지 않고 기존 1행 헤더 이름을 기준으로 행을 재배치합니다. 기존 Reports의 StudentKey가 비어 있어도 조회 시 과정·학교·이름으로 계산됩니다.
DEPLOY

3. Apps Script 웹 앱 새 버전 배포

  1. 배포 → 배포 관리 → 기존 웹 앱 편집
  2. 버전을 새 버전으로 선택
  3. 실행 사용자: 나, 액세스: 모든 사용자
  4. 배포 후 /exec URL을 확인
Code.gs를 수정했으므로 반드시 새 버전으로 재배포해야 합니다. 시험 JSON이나 디자인만 수정한 경우에는 GitHub Pages만 다시 배포합니다.
GITHUB PAGES

4. 사이트 파일 배포

  1. 전체 프로젝트 ZIP을 업로드하거나 패치 ZIP을 기존 저장소에 덮어씁니다.
  2. GitHub Pages가 site/를 배포하도록 설정합니다.
  3. 교사용 화면의 서버 설정에서 Apps Script URL과 WRITE_KEY를 저장합니다.
  4. 연결 확인 후 시험 설정 서버 동기화를 실행합니다.

정상 동기화 수치는 과정 3, 시험 39, 문항 108입니다.

ONE CLICK

7. 학생 저장과 링크 전달

  1. 학생 이름과 학교를 입력합니다.
  2. 객관식 정오표와 서술형 점수를 입력합니다.
  3. 저장·성적 분석·링크 복사 버튼을 누릅니다.
  4. 복사된 링크를 학부모에게 전달합니다.

Google Sheets 저장, 평가 통계 재계산, 복습 기록 연결, 무작위 링크 생성, 클립보드 복사가 한 번에 처리됩니다.

PARENT REPORT

8. 리포트 학습 순서

  1. 복습 누적 성취와 총괄 결과를 비교합니다.
  2. 단원별 강점과 보완 영역을 확인합니다.
  3. 오답 원문을 다시 풀어 답을 제출합니다.
  4. 제출 후 검수된 정답·해설·공식·부분점수 기준을 봅니다.
  5. 새 동형 문제를 풀고 제출 후 정답·해설을 확인합니다.
CURRENT STATUS

9. 현재 자료 등록 상태

물리1 역학과 전자기·파동 총괄평가는 25문항 전체의 검수된 정답·해설·루브릭·원문 재도전·동형 문제가 등록되었습니다. 물리2와 물리1심화 총괄평가는 연결 정책만 등록되어 있으며 시험지와 해설지 제공 후 활성화합니다.
